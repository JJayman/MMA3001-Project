treeskel.measure_width

Measure the leaders' widths in the winter photos, to set and check the width model.

Until session 8 the leaders were drawn about half as wide as their bark: their widths came from scale-space ridge detection, which responds to the sunlit half of a branch lit from one side. They are now measured across the branch in the colour image (treeskel.guided_gt.branch_edges()) and drawn at each leader's own width, widened near the fork by a shared amount (treeskel.guided_gt.fit_leader_radius()). This module measures, on development-row trees only, and only with cross-sections that cannot reach the other leader (near the fork they would take it in too, see treeskel.guided_gt.clear_of()):

  1. Depth overshoot. Depth is a second, independent sensor, but its silhouette reaches past a branch's edges. Where the depth run through a cross-section ends in "no reading" on both sides (nothing behind to merge with) and the colour changes sharply at an edge, the depth edge minus the colour edge measures the overshoot (edge_overshoot()).
  2. Agreement per leader. Each leader's drawn width far from the fork (at least 8 trunk radii), before and after, against the depth width there minus the overshoot.
  3. Width along the leaders. Pooled medians by distance from the fork, relative to the trunk's radius at the fork: the new cross-section widths, the old drawn radii, the raw depth width, and the provided hand masks (hand_mask_profiles()), which are drawn on the summer photos but whose ratios need no alignment.
  4. The fork widening. Each leader's widths beyond 1.5 trunk radii are fitted as c · (1 + w · exp(−s / (L · R))) with c per leader and (w, L) shared, over a grid (widening_costs()). The shared values are chosen with each tree, and each fold of the row-grouped cross-validation in splits.json, held out in turn (choose_shape()), and compared with a constant width (w = 0). The whole cost surface is saved, and the free straight tapers used before are summarised.
  5. The crotch. Mask pixels between the leaders near the fork that are off the depth silhouette (treeskel.measure_fork.crotch_zone()), before and after, and after without the widening: wider leaders fill the bottom of the V. "Before" has the trunk's round top (and the shoulder fill), "after" the current fork junction; treeskel.measure_fork compares the two ways of drawing the fork on the same leaders.
  6. Centring. How far the traced path is from the bark's centre (the middle of the two edges found across it); the mask is centred on the path.

Usage, from the command line:

python -m treeskel.measure_width data/raw --clicks annotations/winter_clicks.json \
    --split splits.json --out outputs/measure_width --figure outputs/leader_width.jpg \
    --plot outputs/leader_width_profiles.png

112def centre_runs(strip: np.ndarray) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
113    """The run of set samples through the middle of each row of a straightened mask.
114
115    Args:
116        strip: ``(N, 2X + 1)`` bool, e.g. the depth foreground sampled
117            across a path (:func:`treeskel.guided_gt.straighten`).
118
119    Returns:
120        ``(first, last, closed)``: offsets (px) of the run's ends, and
121        whether the run is set at the centre and ends inside the row on
122        both sides (so nothing next to it merged into it beyond the row).
123    """
124    half = strip.shape[1] // 2
125    left, right = ~strip[:, half::-1], ~strip[:, half:]           # outwards from the centre
126    steps_l = np.where(left.any(1), left.argmax(1), half + 1)
127    steps_r = np.where(right.any(1), right.argmax(1), half + 1)
128    closed = strip[:, half] & left.any(1) & right.any(1)
129    return 1 - steps_l, steps_r - 1, closed

132def edge_overshoot(grey: np.ndarray, first: np.ndarray, last: np.ndarray, d_first: np.ndarray,
133                   d_last: np.ndarray, closed: np.ndarray, contrast: float = CONTRAST,
134                   max_gap: int = 6) -> np.ndarray:
135    """How far the depth silhouette reaches past clear colour edges (px, outwards positive).
136
137    Args:
138        grey: ``(N, 2X + 1)`` straightened grey levels (0–255).
139        first: Colour edge offsets per cross-section (px).
140        last: The other colour edge's offsets (px).
141        d_first: The depth run's first offsets per cross-section (px).
142        d_last: Its last offsets (px).
143        closed: Cross-sections whose depth run is closed (:func:`centre_runs`).
144        contrast: Least change in mean grey level across a colour edge
145            (3 samples each side) for it to count as clear.
146        max_gap: Edges further apart than this are left out (depth merged
147            with something, or a depth hole).
148
149    Returns:
150        1-D array of overshoots, one per clear edge.
151    """
152    half = grey.shape[1] // 2
153    out = []
154    for i in np.nonzero(closed)[0]:
155        g = grey[i]
156        for edge, d_edge, outward in ((first[i], d_first[i], -1), (last[i], d_last[i], 1)):
157            inside = g[np.clip(half + edge - outward * np.arange(3), 0, len(g) - 1)].mean()
158            outside = g[np.clip(half + edge + outward * np.arange(1, 4), 0, len(g) - 1)].mean()
159            gap = outward * (d_edge - edge)
160            if abs(inside - outside) > contrast and abs(gap) <= max_gap:
161                out.append(gap)
162    return np.array(out, float)

165def hand_mask_profiles(mask: np.ndarray) -> dict | None:
166    """Width along the trunk and leaders of a hand-drawn mask, relative to its trunk.
167
168    The mask is thinned to its centre lines, the root, fork and two leaders
169    are picked as for the winter depth (:func:`treeskel.winter_gt.find_main_branches`),
170    and the half-width at each centre-line point is its distance to the
171    mask's edge. Everything is divided by the trunk's half-width ``T`` (the
172    median 3–40 mask px below the fork), so the mask's scale does not matter.
173
174    Args:
175        mask: A 256x256 boolean hand mask.
176
177    Returns:
178        ``{"left": (s/T, w/T), "right": (s/T, w/T)}`` with ``s`` measured
179        from the fork, or None if no fork is found.
180    """
181    m = ndi.binary_fill_holes(mask)
182    sk = skeletonize(m)
183    lab, n = ndi.label(sk, np.ones((3, 3)))
184    if n > 1:
185        sk = lab == (np.argmax(ndi.sum(sk, lab, range(1, n + 1))) + 1)
186    br = find_main_branches(m, sk)
187    if br["fork"] is None:
188        return None
189    edt = ndi.distance_transform_edt(m)
190    trunk = br["trunk"][::-1]                                       # from the fork down
191    s, w = arc_length(trunk), edt[trunk[:, 0], trunk[:, 1]]
192    near = (s > 3) & (s < 40)
193    t = float(np.median(w[near])) if near.sum() > 3 else float(np.median(w))
194    return {side: (arc_length(br[side]) / t, edt[br[side][:, 0], br[side][:, 1]] / t) for side in ("left", "right")}

197def widening_costs(s_over_r: np.ndarray, widths: np.ndarray, widenings: Sequence[float] = WIDENINGS,
198                   lengths: Sequence[float] = LENGTHS, start: float = FIT_START, min_valid: float = 2.5) -> np.ndarray:
199    """Robust misfit of one leader's widths for each shared widening shape.
200
201    For each ``(w, L)``, the leader's own width ``c`` is the Huber average of
202    ``widths / (1 + w · exp(−s/(L·R)))`` (as in
203    :func:`treeskel.guided_gt.fit_leader_radius`) and the cost is the mean
204    Huber loss (scale :data:`HUBER_SCALE`) of the residuals. Only points at
205    least ``start`` trunk radii from the fork with widths above
206    ``min_valid`` are used.
207
208    Args:
209        s_over_r: ``(N,)`` distance from the fork, in trunk radii.
210        widths: ``(N,)`` measured half-widths (px).
211        widenings: The shared widenings ``w`` tried.
212        lengths: The fade lengths ``L`` tried, in trunk radii.
213        start: Nearest distance from the fork used, in trunk radii.
214        min_valid: Widths at or below this (px) are failed edges, not used.
215
216    Returns:
217        ``(len(widenings), len(lengths))`` costs (nan if too few points).
218    """
219    use = (s_over_r >= start) & (widths > min_valid)
220    out = np.full((len(widenings), len(lengths)), np.nan)
221    if use.sum() < 8:
222        return out
223    s, y = s_over_r[use], widths[use]
224    k = 1.345 * HUBER_SCALE
225    for i, w in enumerate(widenings):
226        for j, length in enumerate(lengths):
227            g = 1 + w * np.exp(-s / length)
228            res = np.abs(y - huber_location(y / g) * g)
229            out[i, j] = float(np.mean(np.where(res <= k, 0.5 * res ** 2, k * (res - 0.5 * k))))
230    return out

233def free_taper(s: np.ndarray, widths: np.ndarray, fork_radius: float, start: float = FIT_START) -> float:
234    """Relative change of a free straight taper from ``start`` trunk radii to the tip (nan if unfit).
235
236    Args:
237        s: ``(N,)`` distance from the fork (px).
238        widths: ``(N,)`` measured half-widths (px).
239        fork_radius: The trunk's radius at the fork (px).
240        start: Nearest distance used, in trunk radii.
241
242    Returns:
243        The fitted line's change from the start to the tip over its width at the start: negative for a branch
244        that narrows. NaN with fewer than 8 widths above 2.5 px, or a fitted width at the start that is not
245        positive.
246    """
247    use = (s >= start * fork_radius) & (widths > 2.5)
248    if use.sum() < 8:
249        return float("nan")
250    a, b = huber_line(s[use], widths[use])
251    base = a + b * s[use].min()
252    return float(b * (s[-1] - s[use].min()) / base) if base > 0 else float("nan")

255def choose_shape(costs: np.ndarray, groups: np.ndarray) -> dict:
256    """Choose the shared widening with each group held out in turn.
257
258    For each group, the ``(w, L)`` with the lowest mean cost over the other
259    groups' leaders is picked, and its mean cost on the held-out group's
260    leaders is compared with a constant width (``w = 0``).
261
262    Args:
263        costs: ``(n_leaders, len(WIDENINGS), len(LENGTHS))`` costs from
264            :func:`widening_costs` (no nan).
265        groups: ``(n_leaders,)`` group of each leader: its tree (to hold out
266            one tree at a time) or its fold of row-grouped cross-validation.
267
268    Returns:
269        ``{"groups", "picks", "held_out", "held_out_constant"}``, one entry per
270        group that has leaders both in and out of it; ``picks`` are
271        ``(w, L)`` pairs.
272    """
273    out: dict = {"groups": [], "picks": [], "held_out": [], "held_out_constant": []}
274    for g in sorted(set(groups.tolist())):
275        train, test = costs[groups != g], costs[groups == g]
276        if not len(train) or not len(test):
277            continue
278        a, b = np.unravel_index(np.argmin(train.mean(0)), train.shape[1:])
279        out["groups"].append(g)
280        out["picks"].append((float(WIDENINGS[a]), float(LENGTHS[b])))
281        out["held_out"].append(float(test[:, a, b].mean()))
282        out["held_out_constant"].append(float(test[:, 0, 0].mean()))
283    return out

286def _held_out_summary(chosen: dict) -> dict:
287    """Ranges of the picks and the mean held-out costs of :func:`choose_shape`."""
288    held, const = np.array(chosen["held_out"]), np.array(chosen["held_out_constant"])
289    return {"widening": [min(p[0] for p in chosen["picks"]), max(p[0] for p in chosen["picks"])],
290            "length": [min(p[1] for p in chosen["picks"]), max(p[1] for p in chosen["picks"])],
291            "picks": [list(p) for p in chosen["picks"]],
292            "held_out_cost": float(held.mean()), "held_out_cost_constant": float(const.mean()),
293            "better_than_constant": int((held < const).sum()), "n_groups": len(held)}

315def measure_tree(job: tuple) -> dict:
316    """All measurements for one tree (top-level so worker processes can run it).
317
318    Args:
319        job: ``(tree_record, clicks, make_tiles)``.
320
321    Returns:
322        Per-leader arrays and summaries, the hand-mask profiles, the depth
323        overshoots and, if asked, crops for the figure.
324    """
325    from treeskel.io import load_mask, load_tree
326
327    rec, clicks, make_tiles = job
328    d = load_tree(rec, "winter")
329    cost, _ = branch_cost(d["rgb"], d["depth"], d["valid"])
330    new = guided_gt(d["rgb"], d["depth"], d["valid"], clicks, cost=cost)
331    old = guided_gt(d["rgb"], d["depth"], d["valid"], clicks, OLD, cost=cost)
332    flat = guided_gt(d["rgb"], d["depth"], d["valid"], clicks, GuidedParams(fork_widening=0), cost=cost)
333    radius = float(new.radii["trunk"][-1])
334    crotch = crotch_zone(new)
335    crotch_px = {name: [int((m & crotch & ~new.tree_mask).sum()), int((m & crotch).sum())]
336                 for name, m in (("before", render_main_branches(old)), ("after", render_main_branches(new)),
337                                 ("after_no_widening", render_main_branches(flat)))}
338    grey = d["rgb"].astype(float).mean(2)
339    half = GuidedParams().profile_half_width
340    leaders, overshoot = [], []
341    for side, other in (("left", new.right), ("right", new.left)):
342        path = getattr(new, side)
343        s = arc_length(path)
344        first, last = branch_edges(d["rgb"], path, half, GuidedParams().profile_along)
345        # Cross-sections that could take in the other leader (near the fork) are not used.
346        clear = clear_of(path, other, half + NEIGHBOUR_MARGIN)
347        widths = np.where(clear, (last - first + 1) / 2.0, np.nan)
348        d_first, d_last, closed = centre_runs(straighten(new.tree_mask.astype(float), path, half, order=0) > 0.5)
349        closed &= clear
350        overshoot.append(edge_overshoot(straighten(grey, path, half), first, last, d_first, d_last, closed))
351        depth_w = np.where(closed, (d_last - d_first + 1) / 2.0, np.nan)
352        far = s >= FAR * radius
353        leaders.append({
354            "side": side, "s_over_r": s / radius, "widths": widths, "depth": depth_w,
355            "first_clear": float(s[clear].min() / radius) if clear.any() else float("nan"),
356            # How far the traced path is from the bark's centre (px), where the edges were found.
357            "off_centre": np.abs((first + last) / 2.0)[clear & (widths > 2.5)],
358            "old": old.radii[side], "new": new.radii[side],
359            "old_far": float(np.median(old.radii[side][far])) if far.any() else float("nan"),
360            "new_far": float(np.median(new.radii[side][far])) if far.any() else float("nan"),
361            "depth_far": float(np.nanmedian(depth_w[far])) if (far & closed).any() else float("nan"),
362            "free_taper": free_taper(s, widths, radius),
363            "costs": widening_costs(s / radius, widths),
364        })
365    hand = None
366    if rec.has_mask:
367        hand = hand_mask_profiles(load_mask(rec.paths[("summer", "mask")]))
368    tiles = None
369    if make_tiles:
370        before, after = render_main_branches(old), render_main_branches(new)
371        tiles = {"whole": [_paint(d["rgb"], before), _paint(d["rgb"], after)], "crops": []}
372        for side in ("left", "right"):
373            path = getattr(new, side)
374            for frac in (0.0, 0.3, 0.6):
375                c = path[int(frac * (len(path) - 1))]
376                tiles["crops"].append([_crop(im, c, 32) for im in (d["rgb"], _outline(d["rgb"], before),
377                                                                  _outline(d["rgb"], after))])
378    return {"tree": rec.tree_id, "row": rec.row, "fork_radius": radius, "leaders": leaders, "hand": hand,
379            "overshoot": np.concatenate(overshoot), "crotch": crotch_px, "tiles": tiles}

396def summarise(results: list[dict], folds: Sequence[Sequence[int]] | None = None) -> dict:
397    """Pool :func:`measure_tree` results into the report.
398
399    Args:
400        results: One :func:`measure_tree` result per tree.
401        folds: Rows in each fold of row-grouped cross-validation (the
402            ``fold_val_rows`` of ``splits.json``), to choose the widening with
403            whole folds held out as well as single trees.
404
405    Returns:
406        The report (``report.json``).
407    """
408    leaders = [(r["tree"], r["fork_radius"], ld) for r in results for ld in r["leaders"]]
409    over = np.concatenate([r["overshoot"] for r in results])
410    bleed = float(np.median(over)) if len(over) else float("nan")
411    first_clear = np.array([ld["first_clear"] for _, _, ld in leaders], float)
412    first_clear = first_clear[~np.isnan(first_clear)]
413    out = {"trees": [r["tree"] for r in results], "n_leaders": len(leaders),
414           "first_clear": {"median": float(np.median(first_clear)) if len(first_clear) else None,
415                           "iqr": [float(v) for v in np.percentile(first_clear, [25, 75])] if len(first_clear)
416                           else None},
417           "overshoot": {"n_edges": int(len(over)), "median": bleed,
418                         "iqr": [float(v) for v in np.percentile(over, [25, 75])] if len(over) else None,

198def widening_costs(s_over_r: np.ndarray, widths: np.ndarray, widenings: Sequence[float] = WIDENINGS,
199                   lengths: Sequence[float] = LENGTHS, start: float = FIT_START, min_valid: float = 2.5) -> np.ndarray:
200    """Robust misfit of one leader's widths for each shared widening shape.
201
202    For each ``(w, L)``, the leader's own width ``c`` is the Huber average of
203    ``widths / (1 + w · exp(−s/(L·R)))`` (as in
204    :func:`treeskel.guided_gt.fit_leader_radius`) and the cost is the mean
205    Huber loss (scale :data:`HUBER_SCALE`) of the residuals. Only points at
206    least ``start`` trunk radii from the fork with widths above
207    ``min_valid`` are used.
208
209    Args:
210        s_over_r: ``(N,)`` distance from the fork, in trunk radii.
211        widths: ``(N,)`` measured half-widths (px).
212        widenings: The shared widenings ``w`` tried.
213        lengths: The fade lengths ``L`` tried, in trunk radii.
214        start: Nearest distance from the fork used, in trunk radii.
215        min_valid: Widths at or below this (px) are failed edges, not used.
216
217    Returns:
218        ``(len(widenings), len(lengths))`` costs (nan if too few points).
219    """
220    use = (s_over_r >= start) & (widths > min_valid)
221    out = np.full((len(widenings), len(lengths)), np.nan)
222    if use.sum() < 8:
223        return out
224    s, y = s_over_r[use], widths[use]
225    k = 1.345 * HUBER_SCALE
226    for i, w in enumerate(widenings):
227        for j, length in enumerate(lengths):
228            g = 1 + w * np.exp(-s / length)
229            res = np.abs(y - huber_location(y / g) * g)
230            out[i, j] = float(np.mean(np.where(res <= k, 0.5 * res ** 2, k * (res - 0.5 * k))))
231    return out
