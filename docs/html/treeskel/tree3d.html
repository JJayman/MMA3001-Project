treeskel.tree3d

The tree in 3D: its plane, the V in that plane, its lean and its sizes, from the 8-bit depth.

The trees are trained flat (a 2D open V on a trellis), so each tree is modelled as a plane in front of the camera. The depth map and the camera are those of treeskel.depth3d (zero 300, focal length 616 px; the scale set so that the median development tree's fork is 2.0 m away). For each tree:

  1. Depth along the skeleton (depth_along()): at every point of the trunk and leaders, the median of the depth readings within 3 px (the centre of a branch; depth reaches about 2 px past each edge). Points with fewer than 5 readings get none.
  2. The tree's plane (fit_plane()): fitted to those 3D points by total least squares (perpendicular distances), made robust with Huber weights, so depth that falls on the background or a post counts little. How far the points lie from it says how flat the tree is.
  3. The skeleton on the plane (on_plane()): every traced point is moved along its pixel's ray to the plane, so the 3D skeleton is complete even where the depth has gaps, and depth noise does not make it jagged.

  4. Measures (tree_measures()):

    • V opening in the plane: the angle between straight lines fitted to the same stretch of each leader as the 2D measure (25–264 px from the fork in the winter photo, treeskel.shape), beside the 2D V opening of that stretch; their difference is the 3D correction to the 2D headline;
    • the plane's lean towards the camera (positive: the top nearer) and its turn (positive: the right side farther), relative to the camera;
    • lean from the vertical and the camera's pitch, where the ground behind the tree gives the vertical (ground_up(); winter only, as the summer canopy hides the ground);
    • sizes: leader lengths in view, the trunk's diameter at the fork (the winter trunk radius, measured from depth, at the fork's distance), and the flatness, in metres.

Angles need only the zero and the focal length; sizes need the scale too (treeskel.depth3d). Every measure is also computed at the ends of the zero's range (262 and 366), at session 2's 255, and at ±5% focal length (SETTINGS); sizes scale with the assumed 1.8–2.2 m.

Summer against winter, tree by tree (development rows): the same from the summer depth, along the skeletons of the lined-up hand masks and of the named U-Net's masks. The V opening in the plane needs no common frame, so it can be compared directly, and tree by tree against the V in the photo (plane_against_photo()); the lean and turn relative to the camera also carry the change of the camera's pose between the seasons. A few plane fits fail (planes turned far from the camera, TURNED), so the summaries are medians and rank correlations.

Usage (development rows only)::

python -m treeskel.tree3d data/raw      # -> docs/results/tree3d/

117def depth_along(depth: np.ndarray, valid: np.ndarray, path: np.ndarray, radius: int = SAMPLE_RADIUS,
118                min_valid: int = MIN_SAMPLES) -> np.ndarray:
119    """The depth value at each point of a path: the median of the readings within ``radius`` px.
120
121    Args:
122        depth: ``(480, 640)`` uint8 depth.
123        valid: Boolean mask of its readings.
124        path: ``(N, 2)`` ``(row, col)`` points.
125        radius: Reach of the median (px).
126        min_valid: Fewest readings within reach.
127
128    Returns:
129        ``(N,)`` floats, NaN where fewer than ``min_valid`` pixels within reach have a reading.
130
131    Example:
132        >>> d = np.zeros((20, 20), np.uint8); d[5:15, 5:15] = 100
133        >>> depth_along(d, d > 0, np.array([[10, 10], [10, 4], [0, 0]])).tolist()
134        [100.0, 100.0, nan]
135    """
136    p = np.rint(np.asarray(path, float).reshape(-1, 2)).astype(int)
137    dy, dx = np.nonzero(np.hypot(*np.mgrid[-radius:radius + 1, -radius:radius + 1]) <= radius)
138    dy, dx = dy - radius, dx - radius
139    h, w = depth.shape
140    rr, cc = p[:, :1] + dy[None], p[:, 1:] + dx[None]
141    inside = (rr >= 0) & (rr < h) & (cc >= 0) & (cc < w)
142    rr, cc = np.clip(rr, 0, h - 1), np.clip(cc, 0, w - 1)
143    ok = valid[rr, cc] & inside
144    v = np.where(ok, depth[rr, cc].astype(float), np.nan)
145    out = np.full(len(p), np.nan)
146    enough = ok.sum(axis=1) >= min_valid
147    if enough.any():
148        out[enough] = np.nanmedian(v[enough], axis=1)
149    return out

152def fit_plane(points: np.ndarray, k: float = 1.345, iters: int = 50) -> dict:
153    """A plane fitted to 3D points by total least squares, made robust with Huber weights.
154
155    Each round fits the plane through the weighted centre whose normal is the weighted points' direction
156    of least spread (the last right singular vector), then weights each point by ``min(1, k s / |d|)``,
157    where ``d`` is its distance from the plane and ``s`` the distances' robust standard deviation
158    (1.4826 × the median absolute deviation).
159
160    Args:
161        points: ``(N, 3)`` points.
162        k: Huber's tuning constant (in robust SDs).
163        iters: Most reweighting rounds.
164
165    Returns:
166        ``{"normal", "centre", "distances", "weights", "rms", "median_abs", "n"}``: the unit normal points
167        towards the camera (at the origin); ``rms`` and ``median_abs`` are of all points' distances.
168
169    Raises:
170        ValueError: If there are fewer than 3 points.
171    """
172    p = np.asarray(points, float).reshape(-1, 3)
173    p = p[np.isfinite(p).all(axis=1)]
174    if len(p) < 3:
175        raise ValueError(f"a plane needs at least 3 points, got {len(p)}")
176    w = np.ones(len(p))
177    for _ in range(iters):
178        c = (w[:, None] * p).sum(0) / w.sum()
179        _, _, vt = np.linalg.svd((p - c) * np.sqrt(w)[:, None], full_matrices=False)
180        n = vt[-1]
181        d = (p - c) @ n
182        s = 1.4826 * np.median(np.abs(d - np.median(d)))
183        new = np.minimum(1.0, k * max(s, 1e-9) / np.maximum(np.abs(d), 1e-12))
184        if np.allclose(new, w, atol=1e-6):
185            break
186        w = new
187    if n @ c > 0:                                     # face the camera
188        n = -n
189    return {"normal": n, "centre": c, "distances": d, "weights": w, "rms": float(np.sqrt(np.mean(d ** 2))),
190            "median_abs": float(np.median(np.abs(d))), "n": int(len(p))}

193def on_plane(rays: np.ndarray, plane: dict) -> np.ndarray:
194    """Where each ray from the camera meets the plane: ``(N, 3)`` points.
195
196    Args:
197        rays: ``(N, 3)`` ray directions from the camera.
198        plane: From :func:`fit_plane` (``normal`` and ``centre``).
199
200    Returns:
201        The ``(N, 3)`` points.
202
203    Example:
204        >>> plane = {"normal": np.array([0.0, 0.0, -1.0]), "centre": np.array([0.0, 0.0, 5.0])}
205        >>> on_plane(np.array([[0.5, -0.2, 1.0]]), plane).tolist()
206        [[2.5, -1.0, 5.0]]
207    """
208    n, c = plane["normal"], plane["centre"]
209    return rays * ((n @ c) / (rays @ n))[:, None]

212def angle(a: np.ndarray, b: np.ndarray) -> float:
213    """Angle between two directions (degrees).
214
215    Args:
216        a: A direction (any length).
217        b: Another direction.
218
219    Returns:
220        The angle in [0, 180].
221    """
222    cos = float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)))
223    return float(np.degrees(np.arccos(np.clip(cos, -1.0, 1.0))))

226def stretch(path: np.ndarray, unit: float, params: ShapeParams = ShapeParams()) -> np.ndarray:
227    """Which points of a leader (fork to tip, image px) lie on the stretch its line is fitted to: from
228    ``start`` to ``reach`` units along it, as :func:`treeskel.shape.leader_part`.
229
230    Args:
231        path: ``(N, 2)`` ``(row, col)`` leader path from the fork.
232        unit: The length unit in the path's pixels.
233        params: ``start`` and ``reach``.
234
235    Returns:
236        ``(N,)`` boolean.
237    """
238    s = arc_length(np.asarray(path, float))
239    return (s >= params.start * unit) & (s <= params.reach * unit)

242def ground_up(depth: np.ndarray, valid: np.ndarray, camera: Camera) -> np.ndarray | None:
243    """The upward vertical in the camera's frame, from the ground behind the tree, or None.
244
245    The ground blocks of :func:`treeskel.depth3d.ground_blocks` (values of at least
246    :data:`treeskel.depth3d.MIN_VALUE`) are put in 3D and a plane fitted (:func:`fit_plane`); its
247    normal, which faces the camera above it, points up.
248
249    Args:
250        depth: ``(480, 640)`` uint8 depth.
251        valid: Boolean mask of its readings.
252        camera: The depth map's zero and the focal length.
253
254    Returns:
255        The ``(3,)`` unit vector, or None if too few ground blocks are found.
256    """
257    b = ground_blocks(depth, valid)
258    b = b[b[:, 2] >= MIN_VALUE]
259    if len(b) < MIN_GROUND_BLOCKS:
260        return None
261    return fit_plane(camera.points(b[:, [1, 0]], b[:, 2]))["normal"]

264def tree_measures(paths: dict, depth: np.ndarray, valid: np.ndarray, camera: Camera, fork_radius: float,
265                  zoom: float = 1.0, up: np.ndarray | None = None, values: dict | None = None,
266                  params: ShapeParams = ShapeParams()) -> dict[str, float]:
267    """One tree's 3D measures (see the module docstring).
268
269    Args:
270        paths: ``{"trunk", "left", "right"}`` ``(N, 2)`` ``(row, col)`` photo points: the trunk from the
271            root to the fork, each leader from the fork to its tip.
272        depth: The photo's ``(480, 640)`` uint8 depth.
273        valid: Boolean mask of the depth's readings.
274        camera: The depth map and camera.
275        fork_radius: The trunk's radius at the fork (photo px).
276        zoom: Photo px per winter px (1 for winter; :data:`treeskel.shape.SUMMER_SCALE` for summer), for
277            the leader stretch.
278        up: The upward vertical (:func:`ground_up`), for the lean from the vertical and the camera's pitch.
279        values: Depth values along each path (:func:`depth_along`), to reuse across camera settings.
280        params: The leader stretch.
281
282    Returns:
283        :data:`MEASURES` (degrees; sizes in units of the scale), NaN where undefined.
284    """
285    out = dict.fromkeys(MEASURES, float("nan"))
286    if values is None:
287        values = {k: depth_along(depth, valid, paths[k]) for k in PARTS}
288    rc = np.concatenate([np.asarray(paths[k], float).reshape(-1, 2) for k in PARTS])
289    v = np.concatenate([values[k] for k in PARTS])
290    ok = np.isfinite(v)
291    out["depth_points"], out["depth_share"] = float(ok.sum()), float(ok.mean()) if len(v) else 0.0
292    if ok.sum() < 20:
293        return out
294    plane = fit_plane(camera.points(rc[ok], v[ok]))
295    n = plane["normal"]
296    on = {k: on_plane(camera.rays(paths[k]), plane) for k in PARTS}
297    unit = UNIT_PX * zoom
298    lines2, lines3 = {}, {}
299    for side in ("left", "right"):
300        m = stretch(paths[side], unit, params)
301        if m.sum() >= params.min_points:
302            lines2[side] = line_direction(to_xy(np.asarray(paths[side], float)[m]))
303            lines3[side] = line_direction(on[side][m])
304    if len(lines3) == 2:
305        out["v_opening_2d"] = angle(lines2["left"], lines2["right"])
306        out["v_opening_3d"] = angle(lines3["left"], lines3["right"])
307        out["correction"] = out["v_opening_3d"] - out["v_opening_2d"]
308    out["lean_camera"] = float(np.degrees(np.arctan2(n[1], -n[2])))      # y is down: the top nearer
309    out["turn"] = float(np.degrees(np.arctan2(n[0], -n[2])))             # the right side farther
310    if up is not None:
311        out["lean_vertical"] = float(np.degrees(np.arcsin(np.clip(-n @ up, -1, 1))))
312        out["camera_pitch"] = float(np.degrees(np.arcsin(np.clip(-up[2], -1, 1))))   # positive: looking down
313    out["flatness_rms"], out["flatness_median"] = plane["rms"], plane["median_abs"]
314    fork = on["trunk"][-1] if len(on["trunk"]) else on["left"][0]
315    out["fork_distance"] = float(fork[2])
316    out["trunk_diameter"] = 2 * fork_radius * float(fork[2]) / camera.focal
317    for side in ("left", "right"):
318        out[f"{side}_length"] = float(arc_length(on[side])[-1]) if len(on[side]) > 1 else float("nan")
319    return out

340def measure_tree(job: tuple) -> list[dict]:
341    """All of one tree's rows (top-level for worker processes): every source and camera setting.
342
343    Args:
344        job: ``(record, winter_trace, hand_mask or None, unet_mask or None)``; the trace as
345            :func:`treeskel.shape.load_traces` gives it, the masks 256x256 (the hand mask lined up).
346
347    Returns:
348        One row per source and camera setting: the tree's 3D measures, or the ``error`` that stopped them.
349    """
350    from treeskel.io import load_tree
351
352    rec, trace, hand, unet = job
353    rows = []
354    winter = load_tree(rec, "winter")
355    sources = [("winter", {k: trace[k] for k in PARTS}, trace["fork_radius"], winter, 1.0)]
356    summer = None
357    for name, mask in (("hand masks", hand), ("U-Net", unet)):
358        mp = mask_paths(mask) if mask is not None else None
359        if mp is not None:
360            summer = summer or load_tree(rec, "summer")
361            sources.append((name, {k: mp[k] for k in PARTS}, mp["fork_radius"], summer, SUMMER_SCALE))
362    for name, paths, radius, images, zoom in sources:
363        values = {k: depth_along(images["depth"], images["valid"], paths[k]) for k in PARTS}
364        for setting, camera in SETTINGS.items():
365            up = ground_up(images["depth"], images["valid"], camera) if name == "winter" else None
366            m = tree_measures(paths, images["depth"], images["valid"], camera, radius, zoom, up, values)
367            rows.append({"tree": rec.tree_id, "row": rec.row, "source": name, "setting": setting, **m})
368    return rows

405def _q(values) -> dict:
406    v = np.asarray([x for x in values if np.isfinite(x)], float)
407    if not len(v):
408        return {"n": 0, "median": None, "q1": None, "q3": None, "p95_abs": None}

421def paired(rows: Sequence[dict], source: str, measure: str, setting: str = "main") -> dict:
422    """A summer source against winter, tree by tree, on one measure: error and agreement.
423
424    Args:
425        rows: One row per tree, source and camera setting (:func:`measure_tree`).
426        source: The summer source (``"hand masks"`` or ``"U-Net"``).
427        measure: The measure compared.
428        setting: The camera setting (:data:`SETTINGS`).
429
430    Returns:
431        ``{"n", "mae", "median_abs", "bias", "r", "spearman"}``: the mean and median absolute difference,
432        the mean difference (summer − winter), and the Pearson and Spearman (rank) correlations. A few
433        failed plane fits dominate the mean and Pearson's r, so the median and the rank correlation are
434        the ones to read.
435    """
436    from scipy import stats
437
438    w = {r["tree"]: r[measure] for r in rows if r["source"] == "winter" and r["setting"] == setting}
439    s = {r["tree"]: r[measure] for r in rows if r["source"] == source and r["setting"] == setting}
440    t = [k for k in s if k in w and np.isfinite(s[k]) and np.isfinite(w[k])]
441    if len(t) < 3:
442        return {"n": len(t)}
443    a, b = np.array([w[k] for k in t]), np.array([s[k] for k in t])
444    e = b - a
445    varied = np.std(b) > 0 and np.std(a) > 0
446    return {"n": len(t), "mae": float(np.mean(np.abs(e))), "median_abs": float(np.median(np.abs(e))),
447            "bias": float(np.mean(e)), "r": float(stats.pearsonr(a, b)[0]) if varied else None,
448            "spearman": float(stats.spearmanr(a, b)[0]) if varied else None}

451def plane_against_photo(rows: Sequence[dict], source: str, setting: str = "main") -> dict:
452    """Does summer agree with winter better in the tree's plane than in the photo? Tree by tree.
453
454    For each tree with both: ``|summer − winter|`` of the V opening in the plane against the same in the
455    photo. The in-plane V does not depend on where the camera stood, which changed between the seasons.
456
457    Args:
458        rows: One row per tree, source and camera setting (:func:`measure_tree`).
459        source: The summer source (``"hand masks"`` or ``"U-Net"``).
460        setting: The camera setting (:data:`SETTINGS`).
461
462    Returns:
463        ``{"n", "plane_closer", "wilcoxon_p", "median_plane", "median_photo"}``.
464    """
465    from scipy import stats
466
467    by = {(r["tree"], r["source"]): r for r in rows if r["setting"] == setting}
468    e3, e2 = [], []
469    for (tree, src), r in by.items():
470        w = by.get((tree, "winter"))
471        if src != source or w is None:
472            continue
473        vals = (r["v_opening_3d"], w["v_opening_3d"], r["v_opening_2d"], w["v_opening_2d"])
474        if all(np.isfinite(v) for v in vals):
475            e3.append(abs(vals[0] - vals[1]))
476            e2.append(abs(vals[2] - vals[3]))
477    if len(e3) < 3:
478        return {"n": len(e3)}
479    e3, e2 = np.array(e3), np.array(e2)
480    d = e2 - e3
481    return {"n": int(len(e3)), "plane_closer": float(np.mean(d > 0)),
482            "wilcoxon_p": float(stats.wilcoxon(d).pvalue) if np.any(d != 0) else 1.0,
483            "median_plane": float(np.median(e3)), "median_photo": float(np.median(e2))}

def fit_plane(points: numpy.ndarray, k: float = 1.345, iters: int = 50) -> dict: 
153def fit_plane(points: np.ndarray, k: float = 1.345, iters: int = 50) -> dict:
154    """A plane fitted to 3D points by total least squares, made robust with Huber weights.
155
156    Each round fits the plane through the weighted centre whose normal is the weighted points' direction
157    of least spread (the last right singular vector), then weights each point by ``min(1, k s / |d|)``,
158    where ``d`` is its distance from the plane and ``s`` the distances' robust standard deviation
159    (1.4826 × the median absolute deviation).
160
161    Args:
162        points: ``(N, 3)`` points.
163        k: Huber's tuning constant (in robust SDs).
164        iters: Most reweighting rounds.
165
166    Returns:
167        ``{"normal", "centre", "distances", "weights", "rms", "median_abs", "n"}``: the unit normal points
168        towards the camera (at the origin); ``rms`` and ``median_abs`` are of all points' distances.
169
170    Raises:
171        ValueError: If there are fewer than 3 points.
172    """
173    p = np.asarray(points, float).reshape(-1, 3)
174    p = p[np.isfinite(p).all(axis=1)]
175    if len(p) < 3:
176        raise ValueError(f"a plane needs at least 3 points, got {len(p)}")
177    w = np.ones(len(p))
178    for _ in range(iters):
179        c = (w[:, None] * p).sum(0) / w.sum()
180        _, _, vt = np.linalg.svd((p - c) * np.sqrt(w)[:, None], full_matrices=False)
181        n = vt[-1]
182        d = (p - c) @ n
183        s = 1.4826 * np.median(np.abs(d - np.median(d)))
184        new = np.minimum(1.0, k * max(s, 1e-9) / np.maximum(np.abs(d), 1e-12))
185        if np.allclose(new, w, atol=1e-6):
186            break
187        w = new
188    if n @ c > 0:                                     # face the camera
189        n = -n
190    return {"normal": n, "centre": c, "distances": d, "weights": w, "rms": float(np.sqrt(np.mean(d ** 2))),
191            "median_abs": float(np.median(np.abs(d))), "n": int(len(p))}
