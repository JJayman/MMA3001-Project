treeskel.tree3d

The tree in 3D: its plane, the V in that plane, its lean and its sizes, from the 8-bit depth.

The trees are trained flat (a 2D open V on a trellis), so each tree is modelled as a plane in front of the camera. The depth map and the camera are those of treeskel.depth3d (zero 300, focal length 616 px; the scale set so that the median development tree's fork is 2.0 m away). For each tree:

  1. Depth along the skeleton (depth_along()): at every point of the trunk and leaders, the median of the depth readings within 3 px (the centre of a branch; depth reaches about 2 px past each edge). Points with fewer than 5 readings get none.
  2. The tree's plane (fit_plane()): fitted to those 3D points by total least squares (perpendicular distances), made robust with Huber weights, so depth that falls on the background or a post counts little. How far the points lie from it says how flat the tree is.
  3. The skeleton on the plane (on_plane()): every traced point is moved along its pixel's ray to the plane, so the 3D skeleton is complete even where the depth has gaps, and depth noise does not make it jagged.

  4. Measures (tree_measures()):

    • V opening in the plane: the angle between straight lines fitted to the same stretch of each leader as the 2D measure (25–264 px from the fork in the winter photo, treeskel.shape), beside the 2D V opening of that stretch; their difference is the 3D correction to the 2D headline;
    • the plane's lean towards the camera (positive: the top nearer) and its turn (positive: the right side farther), relative to the camera;
    • lean from the vertical and the camera's pitch, where the ground behind the tree gives the vertical (ground_up(); winter only, as the summer canopy hides the ground);
    • sizes: leader lengths in view, the trunk's diameter at the fork (the winter trunk radius, measured from depth, at the fork's distance), and the flatness, in metres.

Angles need only the zero and the focal length; sizes need the scale too (treeskel.depth3d). Every measure is also computed at the ends of the zero's range (262 and 366), at session 2's 255, and at ±5% focal length (SETTINGS); sizes scale with the assumed 1.8–2.2 m.

Summer against winter, tree by tree (development rows): the same from the summer depth, along the skeletons of the lined-up hand masks and of the named U-Net's masks. The V opening in the plane needs no common frame, so it can be compared directly, and tree by tree against the V in the photo (plane_against_photo()); the lean and turn relative to the camera also carry the change of the camera's pose between the seasons. A few plane fits fail (planes turned far from the camera, TURNED), so the summaries are medians and rank correlations.

Usage (development rows only)::

python -m treeskel.tree3d data/raw      # -> docs/results/tree3d/

117def depth_along(depth: np.ndarray, valid: np.ndarray, path: np.ndarray, radius: int = SAMPLE_RADIUS,
118                min_valid: int = MIN_SAMPLES) -> np.ndarray:
119    """The depth value at each point of a path: the median of the readings within ``radius`` px.
120
121    Returns:
122        ``(N,)`` floats, NaN where fewer than ``min_valid`` pixels within reach have a reading.
123
124    Example:
125        >>> d = np.zeros((20, 20), np.uint8); d[5:15, 5:15] = 100
126        >>> depth_along(d, d > 0, np.array([[10, 10], [10, 4], [0, 0]])).tolist()
127        [100.0, 100.0, nan]
128    """
129    p = np.rint(np.asarray(path, float).reshape(-1, 2)).astype(int)
130    dy, dx = np.nonzero(np.hypot(*np.mgrid[-radius:radius + 1, -radius:radius + 1]) <= radius)
131    dy, dx = dy - radius, dx - radius
132    h, w = depth.shape
133    rr, cc = p[:, :1] + dy[None], p[:, 1:] + dx[None]
134    inside = (rr >= 0) & (rr < h) & (cc >= 0) & (cc < w)
135    rr, cc = np.clip(rr, 0, h - 1), np.clip(cc, 0, w - 1)
136    ok = valid[rr, cc] & inside
137    v = np.where(ok, depth[rr, cc].astype(float), np.nan)
138    out = np.full(len(p), np.nan)
139    enough = ok.sum(axis=1) >= min_valid
140    if enough.any():
141        out[enough] = np.nanmedian(v[enough], axis=1)
142    return out

145def fit_plane(points: np.ndarray, k: float = 1.345, iters: int = 50) -> dict:
146    """A plane fitted to 3D points by total least squares, made robust with Huber weights.
147
148    Each round fits the plane through the weighted centre whose normal is the weighted points' direction
149    of least spread (the last right singular vector), then weights each point by ``min(1, k s / |d|)``,
150    where ``d`` is its distance from the plane and ``s`` the distances' robust standard deviation
151    (1.4826 × the median absolute deviation).
152
153    Returns:
154        ``{"normal", "centre", "distances", "weights", "rms", "median_abs", "n"}``: the unit normal points
155        towards the camera (at the origin); ``rms`` and ``median_abs`` are of all points' distances.
156    """
157    p = np.asarray(points, float).reshape(-1, 3)
158    p = p[np.isfinite(p).all(axis=1)]
159    if len(p) < 3:
160        raise ValueError(f"a plane needs at least 3 points, got {len(p)}")
161    w = np.ones(len(p))
162    for _ in range(iters):
163        c = (w[:, None] * p).sum(0) / w.sum()
164        _, _, vt = np.linalg.svd((p - c) * np.sqrt(w)[:, None], full_matrices=False)
165        n = vt[-1]
166        d = (p - c) @ n
167        s = 1.4826 * np.median(np.abs(d - np.median(d)))
168        new = np.minimum(1.0, k * max(s, 1e-9) / np.maximum(np.abs(d), 1e-12))
169        if np.allclose(new, w, atol=1e-6):
170            break
171        w = new
172    if n @ c > 0:                                     # face the camera
173        n = -n
174    return {"normal": n, "centre": c, "distances": d, "weights": w, "rms": float(np.sqrt(np.mean(d ** 2))),
175            "median_abs": float(np.median(np.abs(d))), "n": int(len(p))}

178def on_plane(rays: np.ndarray, plane: dict) -> np.ndarray:
179    """Where each ray from the camera meets the plane: ``(N, 3)`` points.
180
181    Example:
182        >>> plane = {"normal": np.array([0.0, 0.0, -1.0]), "centre": np.array([0.0, 0.0, 5.0])}
183        >>> on_plane(np.array([[0.5, -0.2, 1.0]]), plane).tolist()
184        [[2.5, -1.0, 5.0]]
185    """
186    n, c = plane["normal"], plane["centre"]
187    return rays * ((n @ c) / (rays @ n))[:, None]

190def angle(a: np.ndarray, b: np.ndarray) -> float:
191    """Angle between two directions (degrees)."""
192    cos = float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)))
193    return float(np.degrees(np.arccos(np.clip(cos, -1.0, 1.0))))

196def stretch(path: np.ndarray, unit: float, params: ShapeParams = ShapeParams()) -> np.ndarray:
197    """Which points of a leader (fork to tip, image px) lie on the stretch its line is fitted to: from
198    ``start`` to ``reach`` units along it, as :func:`treeskel.shape.leader_part`."""
199    s = arc_length(np.asarray(path, float))
200    return (s >= params.start * unit) & (s <= params.reach * unit)

203def ground_up(depth: np.ndarray, valid: np.ndarray, camera: Camera) -> np.ndarray | None:
204    """The upward vertical in the camera's frame, from the ground behind the tree, or None.
205
206    The ground blocks of :func:`treeskel.depth3d.ground_blocks` (values of at least
207    :data:`treeskel.depth3d.MIN_VALUE`) are put in 3D and a plane fitted (:func:`fit_plane`); its
208    normal, which faces the camera above it, points up.
209    """
210    b = ground_blocks(depth, valid)
211    b = b[b[:, 2] >= MIN_VALUE]
212    if len(b) < MIN_GROUND_BLOCKS:
213        return None
214    return fit_plane(camera.points(b[:, [1, 0]], b[:, 2]))["normal"]

217def tree_measures(paths: dict, depth: np.ndarray, valid: np.ndarray, camera: Camera, fork_radius: float,
218                  zoom: float = 1.0, up: np.ndarray | None = None, values: dict | None = None,
219                  params: ShapeParams = ShapeParams()) -> dict[str, float]:
220    """One tree's 3D measures (see the module docstring).
221
222    Args:
223        paths: ``{"trunk", "left", "right"}`` ``(N, 2)`` ``(row, col)`` photo points: the trunk from the
224            root to the fork, each leader from the fork to its tip.
225        depth, valid: The photo's depth and where it has readings.
226        camera: The depth map and camera.
227        fork_radius: The trunk's radius at the fork (photo px).
228        zoom: Photo px per winter px (1 for winter; :data:`treeskel.shape.SUMMER_SCALE` for summer), for
229            the leader stretch.
230        up: The upward vertical (:func:`ground_up`), for the lean from the vertical and the camera's pitch.
231        values: Depth values along each path (:func:`depth_along`), to reuse across camera settings.
232        params: The leader stretch.
233
234    Returns:
235        :data:`MEASURES` (degrees; sizes in units of the scale), NaN where undefined.
236    """
237    out = dict.fromkeys(MEASURES, float("nan"))
238    if values is None:
239        values = {k: depth_along(depth, valid, paths[k]) for k in PARTS}
240    rc = np.concatenate([np.asarray(paths[k], float).reshape(-1, 2) for k in PARTS])
241    v = np.concatenate([values[k] for k in PARTS])
242    ok = np.isfinite(v)
243    out["depth_points"], out["depth_share"] = float(ok.sum()), float(ok.mean()) if len(v) else 0.0
244    if ok.sum() < 20:
245        return out
246    plane = fit_plane(camera.points(rc[ok], v[ok]))
247    n = plane["normal"]
248    on = {k: on_plane(camera.rays(paths[k]), plane) for k in PARTS}
249    unit = UNIT_PX * zoom
250    lines2, lines3 = {}, {}
251    for side in ("left", "right"):
252        m = stretch(paths[side], unit, params)
253        if m.sum() >= params.min_points:
254            lines2[side] = line_direction(to_xy(np.asarray(paths[side], float)[m]))
255            lines3[side] = line_direction(on[side][m])
256    if len(lines3) == 2:
257        out["v_opening_2d"] = angle(lines2["left"], lines2["right"])
258        out["v_opening_3d"] = angle(lines3["left"], lines3["right"])
259        out["correction"] = out["v_opening_3d"] - out["v_opening_2d"]
260    out["lean_camera"] = float(np.degrees(np.arctan2(n[1], -n[2])))      # y is down: the top nearer
261    out["turn"] = float(np.degrees(np.arctan2(n[0], -n[2])))             # the right side farther
262    if up is not None:
263        out["lean_vertical"] = float(np.degrees(np.arcsin(np.clip(-n @ up, -1, 1))))
264        out["camera_pitch"] = float(np.degrees(np.arcsin(np.clip(-up[2], -1, 1))))   # positive: looking down
265    out["flatness_rms"], out["flatness_median"] = plane["rms"], plane["median_abs"]
266    fork = on["trunk"][-1] if len(on["trunk"]) else on["left"][0]
267    out["fork_distance"] = float(fork[2])
268    out["trunk_diameter"] = 2 * fork_radius * float(fork[2]) / camera.focal
269    for side in ("left", "right"):
270        out[f"{side}_length"] = float(arc_length(on[side])[-1]) if len(on[side]) > 1 else float("nan")
271    return out

285def measure_tree(job: tuple) -> list[dict]:
286    """All of one tree's rows (top-level for worker processes): every source and camera setting.
287
288    Args:
289        job: ``(record, winter_trace, hand_mask or None, unet_mask or None)``; the trace as
290            :func:`treeskel.shape.load_traces` gives it, the masks 256x256 (the hand mask lined up).
291    """
292    from treeskel.io import load_tree
293
294    rec, trace, hand, unet = job
295    rows = []
296    winter = load_tree(rec, "winter")
297    sources = [("winter", {k: trace[k] for k in PARTS}, trace["fork_radius"], winter, 1.0)]
298    summer = None
299    for name, mask in (("hand masks", hand), ("U-Net", unet)):
300        mp = mask_paths(mask) if mask is not None else None
301        if mp is not None:
302            summer = summer or load_tree(rec, "summer")
303            sources.append((name, {k: mp[k] for k in PARTS}, mp["fork_radius"], summer, SUMMER_SCALE))
304    for name, paths, radius, images, zoom in sources:
305        values = {k: depth_along(images["depth"], images["valid"], paths[k]) for k in PARTS}
306        for setting, camera in SETTINGS.items():
307            up = ground_up(images["depth"], images["valid"], camera) if name == "winter" else None
308            m = tree_measures(paths, images["depth"], images["valid"], camera, radius, zoom, up, values)
309            rows.append({"tree": rec.tree_id, "row": rec.row, "source": name, "setting": setting, **m})
310    return rows

332def _q(values) -> dict:
333    v = np.asarray([x for x in values if np.isfinite(x)], float)

348def paired(rows: Sequence[dict], source: str, measure: str, setting: str = "main") -> dict:
349    """A summer source against winter, tree by tree, on one measure: error and agreement.
350
351    Returns:
352        ``{"n", "mae", "median_abs", "bias", "r", "spearman"}``: the mean and median absolute difference,
353        the mean difference (summer − winter), and the Pearson and Spearman (rank) correlations. A few
354        failed plane fits dominate the mean and Pearson's r, so the median and the rank correlation are
355        the ones to read.
356    """
357    from scipy import stats
358
359    w = {r["tree"]: r[measure] for r in rows if r["source"] == "winter" and r["setting"] == setting}
360    s = {r["tree"]: r[measure] for r in rows if r["source"] == source and r["setting"] == setting}
361    t = [k for k in s if k in w and np.isfinite(s[k]) and np.isfinite(w[k])]
362    if len(t) < 3:
363        return {"n": len(t)}
364    a, b = np.array([w[k] for k in t]), np.array([s[k] for k in t])
365    e = b - a
366    varied = np.std(b) > 0 and np.std(a) > 0
367    return {"n": len(t), "mae": float(np.mean(np.abs(e))), "median_abs": float(np.median(np.abs(e))),
368            "bias": float(np.mean(e)), "r": float(stats.pearsonr(a, b)[0]) if varied else None,
369            "spearman": float(stats.spearmanr(a, b)[0]) if varied else None}

372def plane_against_photo(rows: Sequence[dict], source: str, setting: str = "main") -> dict:
373    """Does summer agree with winter better in the tree's plane than in the photo? Tree by tree.
374
375    For each tree with both: ``|summer − winter|`` of the V opening in the plane against the same in the
376    photo. The in-plane V does not depend on where the camera stood, which changed between the seasons.
377
378    Returns:
379        ``{"n", "plane_closer", "wilcoxon_p", "median_plane", "median_photo"}``.
380    """
381    from scipy import stats
382
383    by = {(r["tree"], r["source"]): r for r in rows if r["setting"] == setting}
384    e3, e2 = [], []
385    for (tree, src), r in by.items():
386        w = by.get((tree, "winter"))
387        if src != source or w is None:
388            continue
389        vals = (r["v_opening_3d"], w["v_opening_3d"], r["v_opening_2d"], w["v_opening_2d"])
390        if all(np.isfinite(v) for v in vals):
391            e3.append(abs(vals[0] - vals[1]))
392            e2.append(abs(vals[2] - vals[3]))
393    if len(e3) < 3:
394        return {"n": len(e3)}
395    e3, e2 = np.array(e3), np.array(e2)
396    d = e2 - e3
397    return {"n": int(len(e3)), "plane_closer": float(np.mean(d > 0)),
398            "wilcoxon_p": float(stats.wilcoxon(d).pvalue) if np.any(d != 0) else 1.0,
399            "median_plane": float(np.median(e3)), "median_photo": float(np.median(e2))}

def fit_plane(points: numpy.ndarray, k: float = 1.345, iters: int = 50) -> dict: 
146def fit_plane(points: np.ndarray, k: float = 1.345, iters: int = 50) -> dict:
147    """A plane fitted to 3D points by total least squares, made robust with Huber weights.
148
149    Each round fits the plane through the weighted centre whose normal is the weighted points' direction
150    of least spread (the last right singular vector), then weights each point by ``min(1, k s / |d|)``,
151    where ``d`` is its distance from the plane and ``s`` the distances' robust standard deviation
152    (1.4826 × the median absolute deviation).
153
154    Returns:
155        ``{"normal", "centre", "distances", "weights", "rms", "median_abs", "n"}``: the unit normal points
156        towards the camera (at the origin); ``rms`` and ``median_abs`` are of all points' distances.
157    """
158    p = np.asarray(points, float).reshape(-1, 3)
159    p = p[np.isfinite(p).all(axis=1)]
160    if len(p) < 3:
161        raise ValueError(f"a plane needs at least 3 points, got {len(p)}")
162    w = np.ones(len(p))
163    for _ in range(iters):
164        c = (w[:, None] * p).sum(0) / w.sum()
165        _, _, vt = np.linalg.svd((p - c) * np.sqrt(w)[:, None], full_matrices=False)
166        n = vt[-1]
167        d = (p - c) @ n
168        s = 1.4826 * np.median(np.abs(d - np.median(d)))
169        new = np.minimum(1.0, k * max(s, 1e-9) / np.maximum(np.abs(d), 1e-12))
170        if np.allclose(new, w, atol=1e-6):
171            break
172        w = new
173    if n @ c > 0:                                     # face the camera
174        n = -n
175    return {"normal": n, "centre": c, "distances": d, "weights": w, "rms": float(np.sqrt(np.mean(d ** 2))),
176            "median_abs": float(np.median(np.abs(d))), "n": int(len(p))}
