treeskel.shape_model

Predict each tree's winter shape from its summer photo, with the row-grouped folds.

The targets are the shape measures of the winter traces (treeskel.shape): the V opening, each leader's angle from the trunk and from the vertical, the V's lean and each leader's bend. They need no alignment between the seasons (session 7 found none reliable). The inputs are features of the summer photo from ResNet-18, a network pretrained on ImageNet: its last feature map averaged over the whole photo and over a 2x2 grid of cells (computed by python -m treeskel.shape on the student's PC and committed in data/shape/). With about 450 trees, a pretrained network used as a fixed feature extractor, with a linear model on top, is the usual first step (transfer learning).

Model (predict_fold()): ridge regression, min ||y − Xw||² + α||w||², on standardised features, solved for every α at once from one singular value decomposition of the training features. Each measure is fitted separately. The mirror image of every training photo is added as a second example, with the mirrored measures (the left and right leaders swap, leans and tilts change sign; treeskel.shape.MIRROR): a free way to double the data, and a mirrored tree is still a real tree. The measures are centred on the training trees' mean first, so a real difference between left and right (or a camera tilt shared by all photos) is kept, and only the tree-to-tree variation is learned from both. A prediction averages the photo's and the mirror of its mirror image's.

Choosing α without the held-out rows (choose_alpha()): within each training set, by row-grouped cross-validation again (nested), so the rows being predicted never influence any choice.

Baselines:

  • mean shape: each measure's mean over the training trees (a model that ignores the photo; any useful model must beat it);
  • hand masks: the same measures from the provided hand-drawn masks, as they are (not fitted to anything): a person's reading of the summer view.

Scores (evaluate()), on the held-out rows of all 5 folds: mean absolute error, root mean squared error, skill 1 − MSE / MSE(mean shape) (0 = no better than the mean shape, 1 = perfect), the correlation with the truth, and each tree's error compared with the mean shape's (the fraction of trees improved and a Wilcoxon signed-rank test). Trees in one row share light and camera settings, so the per-fold skills are also shown: a model that only helps in one fold is not reliable.

Usage, from the command line:

python -m treeskel.shape_model --plots docs/figures   # data/shape/ -> docs/results/shape/

 87def feature_matrix(arrays: dict[str, np.ndarray], name: str) -> np.ndarray:

 99def mirror_matrix(names: Sequence[str] = MEASURES) -> np.ndarray:
100    """The matrix ``M`` with ``mirror(y) = y @ M`` for rows ``y`` of the measures ``names``.
101
102    Example:
103        >>> m = mirror_matrix(("left_bend", "right_bend", "lean"))
104        >>> (np.array([[1.0, 2.0, 3.0]]) @ m).tolist()
105        [[2.0, 1.0, -3.0]]
106    """
107    idx = {k: i for i, k in enumerate(names)}
108    m = np.zeros((len(names), len(names)))
109    for k, src in MIRROR.items():
110        if k in idx:
111            sign, src = (-1.0, src[1:]) if src.startswith("-") else (1.0, src)
112            m[idx[src], idx[k]] = sign
113    return m

133class RidgePath:
134    """Ridge regression for many penalties at once, from one SVD.
135
136    The features are standardised with the training mean and standard
137    deviation, the targets centred on their training mean (so the intercept
138    is not penalised). With ``X = U S Vᵀ``, the solution for penalty ``α`` is
139    ``w = V diag(s / (s² + α)) Uᵀ y``.
140
141    Args:
142        x: ``(n, D)`` training features.
143        y: ``(n,)`` or ``(n, k)`` training targets (already centred if the
144            caller wants its own centre; the model centres them again).
145    """
146
147    def __init__(self, x: np.ndarray, y: np.ndarray):
148        """Standardise the features, centre the targets and take the SVD once."""
149        self.mu = x.mean(0)
150        self.sd = x.std(0)
151        self.sd[self.sd < 1e-6] = 1.0                       # constant features contribute nothing
152        z = (x - self.mu) / self.sd
153        y = y.reshape(len(y), -1)
154        self.y0 = y.mean(0)
155        self.u, self.s, self.vt = np.linalg.svd(z, full_matrices=False)
156        self.uty = self.u.T @ (y - self.y0)
157
158    def predict(self, x: np.ndarray, alphas: Sequence[float]) -> np.ndarray:
159        """``(len(alphas), m, k)`` predictions for ``(m, D)`` features."""
160        z = (x - self.mu) / self.sd
161        zv = z @ self.vt.T                                  # (m, r)
162        out = [(zv * (self.s / (self.s ** 2 + a))) @ self.uty + self.y0 for a in alphas]
163        return np.stack(out)

166def _augment(x2: np.ndarray, y: np.ndarray, m: np.ndarray | None) -> tuple[np.ndarray, np.ndarray]:
167    """Training examples: the photos with their targets, and (if ``m`` is given) the mirror images with
168    the mirrored targets. ``x2`` is ``(n, 2, D)``, ``y`` is ``(n, k)`` centred targets."""
169    if m is None:
170        return x2[:, 0], y
171    return np.concatenate([x2[:, 0], x2[:, 1]]), np.concatenate([y, y @ m])

174def _combine(pred_photo: np.ndarray, pred_mirror: np.ndarray, m: np.ndarray | None) -> np.ndarray:
175    """Average a photo's prediction with the mirrored prediction for its mirror image (if mirroring)."""
176    return pred_photo if m is None else (pred_photo + pred_mirror @ m) / 2

179def fit_predict(x2_train: np.ndarray, y_train: np.ndarray, x2_test: np.ndarray, alphas: Sequence[float],
180                names: Sequence[str], mirror: bool = True) -> np.ndarray:
181    """Ridge predictions for every penalty, for measures with no missing values in ``y_train``.
182
183    Args:
184        x2_train, x2_test: ``(n, 2, D)`` features (photo, mirror image).
185        y_train: ``(n, k)`` targets for the measures ``names``, no NaN.
186        alphas: Penalties.
187        names: The measures' names (for the mirror matrix; all of a mirrored
188            pair must be present if ``mirror``).
189        mirror: Train on the mirror images too, and average the two predictions.
190
191    Returns:
192        ``(len(alphas), m, k)`` predictions.
193    """
194    m = mirror_matrix(names) if mirror else None
195    centre = y_train.mean(0)
196    x, y = _augment(x2_train, y_train - centre, m)
197    model = RidgePath(x, y)
198    p = model.predict(np.concatenate([x2_test[:, 0], x2_test[:, 1]]), alphas)
199    n = len(x2_test)
200    return _combine(p[:, :n], p[:, n:], m) + centre

203def _groups(names: Sequence[str]) -> list[tuple[str, ...]]:
204    """The measures split into groups closed under mirroring (each is fitted with its mirror partner)."""
205    left = list(names)
206    groups = []
207    while left:
208        k = left.pop(0)
209        partner = MIRROR[k].lstrip("-")
210        if partner != k and partner in left:
211            left.remove(partner)
212            groups.append((k, partner))
213        else:
214            groups.append((k,))
215    return groups

218def predict_all(x2_train: np.ndarray, y_train: np.ndarray, x2_test: np.ndarray, alphas: Sequence[float],
219                names: Sequence[str] = MEASURES, mirror: bool = True) -> np.ndarray:
220    """:func:`fit_predict` for every measure, each group on the training trees where it is known.
221
222    Returns:
223        ``(len(alphas), m, len(names))`` predictions (NaN only if a group has
224        fewer than 3 known training trees).
225    """
226    out = np.full((len(alphas), len(x2_test), len(names)), np.nan)
227    for g in _groups(names):
228        cols = [names.index(k) for k in g]
229        ok = np.isfinite(y_train[:, cols]).all(1)
230        if ok.sum() >= 3:
231            out[:, :, cols] = fit_predict(x2_train[ok], y_train[ok][:, cols], x2_test, alphas, g, mirror)
232    return out

235def choose_alpha(x2: np.ndarray, y: np.ndarray, rows: np.ndarray, alphas: Sequence[float] = ALPHAS,
236                 names: Sequence[str] = MEASURES, mirror: bool = True, n_splits: int = 4) -> np.ndarray:
237    """The penalty for each measure with the smallest row-grouped cross-validated squared error.
238
239    Args:
240        x2: ``(n, 2, D)`` training features.
241        y: ``(n, k)`` training targets (NaN = unknown).
242        rows: ``(n,)`` orchard row of each tree (the groups).
243        alphas, names, mirror: As for :func:`predict_all`.
244        n_splits: Inner folds (fewer if there are fewer rows).
245
246    Returns:
247        ``(k,)`` chosen penalties.
248    """
249    from sklearn.model_selection import GroupKFold
250
251    k = min(n_splits, len(set(rows.tolist())))
252    sse = np.zeros((len(alphas), y.shape[1]))
253    for tr, va in GroupKFold(n_splits=k).split(x2, groups=rows):
254        p = predict_all(x2[tr], y[tr], x2[va], alphas, names, mirror)
255        err = (p - y[va][None]) ** 2
256        sse += np.nansum(err, axis=1)
257    return np.asarray(alphas)[np.argmin(sse, axis=0)]

260def cross_validate(x2: np.ndarray, y: np.ndarray, rows: np.ndarray, fold_rows: Sequence[Sequence[int]],
261                   alphas: Sequence[float] = ALPHAS, names: Sequence[str] = MEASURES,
262                   mirror: bool = True) -> dict:
263    """Ridge and mean-shape predictions for every tree, each from the fold that holds its row out.
264
265    Args:
266        x2: ``(n, 2, D)`` features of the development trees.
267        y: ``(n, k)`` winter measures (NaN = unknown).
268        rows: ``(n,)`` orchard rows.
269        fold_rows: The held-out rows of each fold (``splits.json``'s ``fold_val_rows``).
270        alphas, names, mirror: As for :func:`predict_all`.
271
272    Returns:
273        ``{"ridge": (n, k), "mean": (n, k), "fold": (n,), "alpha": (folds, k),
274        "alpha_at_edge": [...]}``.
275    """
276    n = len(y)
277    ridge, mean = np.full((n, len(names)), np.nan), np.full((n, len(names)), np.nan)
278    fold = np.full(n, -1)
279    chosen, edge = [], []
280    for i, held in enumerate(fold_rows):
281        va = np.isin(rows, list(held))
282        tr = ~va
283        if not va.any():
284            continue
285        fold[va] = i
286        a = choose_alpha(x2[tr], y[tr], rows[tr], alphas, names, mirror)
287        chosen.append(a.tolist())
288        for j, name in enumerate(names):
289            if a[j] in (alphas[0], alphas[-1]):
290                edge.append(f"fold {i} {name}: {a[j]:g}")
291        # One fit gives every penalty's predictions; each measure takes its own penalty's.
292        p = predict_all(x2[tr], y[tr], x2[va], alphas, names, mirror)
293        which = [list(alphas).index(v) for v in a]
294        ridge[va] = p[which, :, range(len(names))].T
295        mean[va] = np.nanmean(y[tr], axis=0)
296    return {"ridge": ridge, "mean": mean, "fold": fold, "alpha": chosen, "alpha_at_edge": edge}

299def evaluate(truth: np.ndarray, pred: np.ndarray, baseline: np.ndarray, fold: np.ndarray | None = None) -> dict:
300    """Scores of one measure's predictions against the truth and the mean-shape baseline.
301
302    Only trees where the truth, the prediction and the baseline are all known count.
303
304    Returns:
305        ``{"n", "mae", "rmse", "skill", "r", "baseline_mae", "improved", "wilcoxon_p",
306        "fold_skill"}``; ``skill`` is ``1 − MSE / MSE(baseline)``.
307    """
308    ok = np.isfinite(truth) & np.isfinite(pred) & np.isfinite(baseline)
309    t, p, b = truth[ok], pred[ok], baseline[ok]
310    if len(t) < 3:
311        return {"n": int(len(t))}
312    e, eb = p - t, b - t
313    mse, mse_b = float(np.mean(e ** 2)), float(np.mean(eb ** 2))
314    diff = np.abs(eb) - np.abs(e)
315    out = {
316        "n": int(len(t)),
317        "mae": float(np.mean(np.abs(e))),
318        "rmse": float(np.sqrt(mse)),
319        "skill": 1 - mse / mse_b if mse_b > 0 else float("nan"),
320        "r": float(np.corrcoef(p, t)[0, 1]) if np.std(p) > 0 else float("nan"),
321        "bias": float(np.mean(e)),
322        "baseline_mae": float(np.mean(np.abs(eb))),
323        "improved": float(np.mean(diff > 0)),
324        "wilcoxon_p": float(stats.wilcoxon(diff).pvalue) if np.any(diff != 0) else 1.0,
325    }
326    if fold is not None:
327        f = fold[ok]
328        out["fold_skill"] = [1 - float(np.mean(e[f == i] ** 2)) / float(np.mean(eb[f == i] ** 2))
329                             if (f == i).sum() > 2 and np.mean(eb[f == i] ** 2) > 0 else None
330                             for i in range(int(f.max()) + 1)]
331    return out

338def print_scores(report: dict, names: Sequence[str]) -> None:
339    """Print the table of scores per measure and model."""

351def run(table: Sequence[dict], ids: Sequence[str], arrays: dict, fold_rows: Sequence[Sequence[int]],
352        feature_sets: Sequence[str] = tuple(FEATURE_SETS), names: Sequence[str] = MEASURES,
353        alphas: Sequence[float] = ALPHAS) -> tuple[dict, dict]:
354    """Cross-validate every feature set (with and without mirroring for ``rgb``) and score all models.
355
356    Returns:
357        ``(report, predictions)``: the scores per measure and model, and the
358        per-tree predictions (``{model: (n, k)}``, the hand masks and the mean
359        shape included, plus ``"truth"``, ``"fold"``, ``"tree"``, ``"row"``).
360    """
361    by_id = {r["tree"]: r for r in table}
362    keep = [i for i, t in enumerate(ids) if t in by_id]
363    trees = [ids[i] for i in keep]
364    rows = np.array([by_id[t]["row"] for t in trees])
365    y = np.array([[by_id[t][f"winter_{k}"] for k in names] for t in trees], float)
366    hand = np.array([[by_id[t][f"hand_{k}"] for k in names] for t in trees], float)
367    models = {}
368    base = None
369    variants = [(f, True) for f in feature_sets] + ([("rgb", False)] if "rgb" in feature_sets else [])
370    for fs, mirror in variants:
371        x2 = feature_matrix(arrays, fs)[keep]
372        cv = cross_validate(x2, y, rows, fold_rows, alphas, names, mirror)
373        label = f"ridge {fs}" + ("" if mirror else " no-mirror")
374        models[label] = cv
375        base = cv
376    preds = {"tree": trees, "row": rows, "truth": y, "fold": base["fold"], "mean shape": base["mean"],
377             "hand masks": hand, **{label: cv["ridge"] for label, cv in models.items()}}
378    report = {"n_trees": len(trees), "fold_rows": [list(map(int, f)) for f in fold_rows],
379              "alphas": {label: cv["alpha"] for label, cv in models.items()},
380              "alpha_at_edge": {label: cv["alpha_at_edge"] for label, cv in models.items() if cv["alpha_at_edge"]},
381              "scores": {}}
382    for j, k in enumerate(names):
383        mean_shape = evaluate(y[:, j], base["mean"][:, j], base["mean"][:, j], base["fold"])
384        mean_shape["r"] = None                      # a constant per fold: its correlation says nothing
385        sc = {"mean shape": mean_shape,
386              "hand masks": evaluate(y[:, j], hand[:, j], base["mean"][:, j], base["fold"])}
387        for label, cv in models.items():
388            sc[label] = evaluate(y[:, j], cv["ridge"][:, j], cv["mean"][:, j], cv["fold"])
389        report["scores"][k] = sc
390    return report, preds

def evaluate( truth: numpy.ndarray, pred: numpy.ndarray, baseline: numpy.ndarray, fold: numpy.ndarray | None = None) -> dict: 
300def evaluate(truth: np.ndarray, pred: np.ndarray, baseline: np.ndarray, fold: np.ndarray | None = None) -> dict:
301    """Scores of one measure's predictions against the truth and the mean-shape baseline.
302
303    Only trees where the truth, the prediction and the baseline are all known count.
304
305    Returns:
306        ``{"n", "mae", "rmse", "skill", "r", "baseline_mae", "improved", "wilcoxon_p",
307        "fold_skill"}``; ``skill`` is ``1 − MSE / MSE(baseline)``.
308    """
309    ok = np.isfinite(truth) & np.isfinite(pred) & np.isfinite(baseline)
310    t, p, b = truth[ok], pred[ok], baseline[ok]
311    if len(t) < 3:
312        return {"n": int(len(t))}
313    e, eb = p - t, b - t
314    mse, mse_b = float(np.mean(e ** 2)), float(np.mean(eb ** 2))
315    diff = np.abs(eb) - np.abs(e)
316    out = {
317        "n": int(len(t)),
318        "mae": float(np.mean(np.abs(e))),
319        "rmse": float(np.sqrt(mse)),
320        "skill": 1 - mse / mse_b if mse_b > 0 else float("nan"),
321        "r": float(np.corrcoef(p, t)[0, 1]) if np.std(p) > 0 else float("nan"),
322        "bias": float(np.mean(e)),
323        "baseline_mae": float(np.mean(np.abs(eb))),
324        "improved": float(np.mean(diff > 0)),
325        "wilcoxon_p": float(stats.wilcoxon(diff).pvalue) if np.any(diff != 0) else 1.0,
326    }
327    if fold is not None:
328        f = fold[ok]
329        out["fold_skill"] = [1 - float(np.mean(e[f == i] ** 2)) / float(np.mean(eb[f == i] ** 2))
330                             if (f == i).sum() > 2 and np.mean(eb[f == i] ** 2) > 0 else None
331                             for i in range(int(f.max()) + 1)]
332    return out
