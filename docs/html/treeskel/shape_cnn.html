treeskel.shape_cnn

Fine-tune a CNN to predict each tree's winter shape from its summer photo, with the row-grouped folds.

Fixed ImageNet features (treeskel.shape_model) predicted the winter shape barely better than the mean shape: skill at most about 0.1. The hand masks showed that a person can read the V from the same photos (skill +0.87 on the V opening). So here the network itself is trained (fine-tuned): ResNet-18, pretrained on ImageNet, with its classifier replaced by a linear layer that outputs the ten shape measures of treeskel.shape. It learns from the summer photos of the training rows and their winter measures only; the hand masks stay for validation (the student's choice, session 10).

Targets. Each measure is centred on the training trees' mean and divided by a spread it shares with its mirror partner (target_scale()), so that a mirror image's targets are exactly the mirrored standardised targets. The loss is the squared error averaged over the measures a tree has (masked_mse()): a tree that splits at the ground has no trunk axis.

Augmentation (augment(), every training step): a random crop of 80–100% of the photo's area, resized back (a change of scale or position changes no angle); jitter in brightness, contrast and saturation; and, half of the time, the mirror image with the mirrored targets. A prediction averages the photo's and the mirror of its mirror image's (predict()).

Validation (cross_validate_cnn()): the 5 row-grouped folds of splits.json.

  1. Within each fold's training rows, the next fold's rows are held out, and the number of epochs is chosen where their loss is lowest.
  2. The network is trained again, from the ImageNet weights, on all the training rows for that many epochs.
  3. It predicts the fold's own rows.

The rows being predicted never influence a choice, and the recipe (CNNParams) was fixed before any result.

Variants (the student's choice after the first run, session 10): the summer depth as a fourth input channel (--depth; the first layer's weights for it start as the mean of its colour weights, and the colour jitter leaves it alone), and the photos at full size (--size 480 640). Each variant saves to its own folder. They are all reported, since choosing the best on the same folds would flatter it.

Usage, from the command line:

python -m treeskel.shape_cnn data/raw                  # the student's PC (GPU); docs/results/shape_cnn/
python -m treeskel.shape_cnn data/raw --depth          # docs/results/shape_cnn_depth/
python -m treeskel.shape_cnn data/raw --size 480 640   # docs/results/shape_cnn_480x640/

108def target_scale(y: np.ndarray, names: Sequence[str] = MEASURES) -> tuple[np.ndarray, np.ndarray]:
109    """Centre and spread for standardising the targets, the spread shared by mirror partners.
110
111    With the left and right bends (and the other pairs) sharing one spread,
112    standardising commutes with mirroring: ``((y − μ) @ M) / s = ((y − μ) / s) @ M``.
113
114    Args:
115        y: ``(n, k)`` training targets (NaN = unknown).
116        names: The measures of the columns.
117
118    Returns:
119        ``(mu, s)``, each ``(k,)``.
120    """
121    with warnings.catch_warnings():                       # a measure no training tree has stays NaN
122        warnings.simplefilter("ignore", RuntimeWarning)
123        mu = np.nanmean(y, axis=0)
124        sd = np.nanstd(y, axis=0)
125    partner = np.abs(mirror_matrix(names)).argmax(axis=0)  # the measure each one's mirror comes from
126    s = (sd + sd[partner]) / 2
127    s[~np.isfinite(s) | (s < 1e-6)] = 1.0
128    return mu, s

131def mirror_columns(names: Sequence[str] = MEASURES) -> tuple[np.ndarray, np.ndarray]:
132    """How to mirror a row of measures by moving and negating columns: ``mirrored = y[:, src] * sign``.
133
134    Unlike multiplying by the mirror matrix, this keeps an unknown (NaN)
135    measure in its own place instead of spreading it (NaN × 0 is NaN).
136
137    Args:
138        names: The measures, in column order.
139
140    Returns:
141        ``(src, sign)``: the column each mirrored column comes from, and its sign (±1).
142
143    Example:
144        >>> src, sign = mirror_columns(("left_bend", "right_bend", "lean"))
145        >>> (np.array([[1.0, np.nan, 3.0]])[:, src] * sign).tolist()
146        [[nan, 1.0, -3.0]]
147    """
148    m = mirror_matrix(names)
149    src = np.abs(m).argmax(axis=0)
150    return src, m[src, np.arange(len(names))]

153def masked_mse(pred, target):
154    """Mean squared error over the known targets (NaN in ``target`` is skipped).
155
156    Args:
157        pred: ``(B, k)`` predictions (tensor).
158        target: ``(B, k)`` targets, NaN where unknown.
159
160    Returns:
161        The loss, a scalar tensor (0 if no target is known).
162    """
163    import torch
164
165    known = torch.isfinite(target)
166    diff = torch.where(known, pred - torch.nan_to_num(target), torch.zeros_like(pred))
167    return (diff ** 2).sum() / known.sum().clamp(min=1)

170def normalise(x):
171    """``(B, 3, H, W)`` floats in [0, 1] to the ImageNet normalisation; a fourth (depth) channel uses
172    :data:`DEPTH_MEAN` and :data:`DEPTH_STD`.
173
174    Args:
175        x: ``(B, 3 or 4, H, W)`` tensor in [0, 1].
176
177    Returns:
178        The normalised tensor.
179    """
180    import torch
181
182    mean, std = list(IMAGENET_MEAN), list(IMAGENET_STD)
183    if x.shape[1] == 4:
184        mean, std = mean + [DEPTH_MEAN], std + [DEPTH_STD]
185    mean = torch.as_tensor(mean, dtype=x.dtype, device=x.device).view(1, -1, 1, 1)
186    std = torch.as_tensor(std, dtype=x.dtype, device=x.device).view(1, -1, 1, 1)
187    return (x - mean) / std

190def augment(x, generator, params: CNNParams = CNNParams(), flip_p: float = 0.5):
191    """Random crop, mirror image and colour jitter for a batch of photos.
192
193    The crop and the mirror are one affine resampling per photo: a square
194    fraction ``f`` of each side (``f² ∈ [crop, 1]`` of the area) at a random
195    position, with the x axis reversed for a mirror image.
196
197    Args:
198        x: ``(B, 3, H, W)`` floats in [0, 1], or ``(B, 4, H, W)`` with the
199            depth last (cropped and mirrored with the photo, but not jittered).
200        generator: A ``torch.Generator`` on ``x``'s device, for repeatable runs.
201        params: ``crop`` and ``jitter``.
202        flip_p: Chance of the mirror image.
203
204    Returns:
205        ``(images, flipped)``: normalised images of ``x``'s shape and a
206        ``(B,)`` bool tensor, True where the mirror image was taken.
207    """
208    import torch
209    import torch.nn.functional as F
210
211    b, dev = x.shape[0], x.device
212
213    def uniform(lo, hi):
214        """``b`` random numbers between ``lo`` and ``hi``, one per image."""
215        return lo + (hi - lo) * torch.rand(b, device=dev, generator=generator)
216
217    f = torch.sqrt(uniform(params.crop, 1.0))                    # side fraction
218    tx, ty = uniform(-1.0, 1.0) * (1 - f), uniform(-1.0, 1.0) * (1 - f)
219    flipped = torch.rand(b, device=dev, generator=generator) < flip_p
220    sx = torch.where(flipped, -f, f)
221    theta = torch.zeros(b, 2, 3, device=dev)
222    theta[:, 0, 0], theta[:, 0, 2], theta[:, 1, 1], theta[:, 1, 2] = sx, tx, f, ty
223    grid = F.affine_grid(theta, list(x.shape), align_corners=False)
224    x = F.grid_sample(x, grid, mode="bilinear", padding_mode="border", align_corners=False)
225    j = params.jitter
226    if j > 0:
227        rgb, rest = x[:, :3], x[:, 3:]                                          # depth is not jittered
228        rgb = rgb * uniform(1 - j, 1 + j).view(b, 1, 1, 1)                     # brightness
229        mean = rgb.mean(dim=(1, 2, 3), keepdim=True)
230        rgb = (rgb - mean) * uniform(1 - j, 1 + j).view(b, 1, 1, 1) + mean      # contrast
231        grey = (0.299 * rgb[:, 0] + 0.587 * rgb[:, 1] + 0.114 * rgb[:, 2]).unsqueeze(1)
232        rgb = grey + (rgb - grey) * uniform(1 - j, 1 + j).view(b, 1, 1, 1)      # saturation
233        x = torch.cat([rgb.clamp(0, 1), rest], dim=1)
234    return normalise(x), flipped

237def make_model(n_out: int, pretrained: bool = True, channels: int = 3):
238    """ResNet-18 with its classifier replaced by a linear layer of ``n_out`` outputs.
239
240    The new layer starts with small weights and zero bias, so the first
241    predictions are near the training mean (0 in standardised units). With
242    ``channels=4`` the first convolution takes a depth channel too; its
243    weights for it start as the mean of its (pretrained) colour weights.
244
245    Args:
246        n_out: Outputs (one per measure).
247        pretrained: Load the ImageNet weights.
248        channels: Input channels: 3 (colour) or 4 (colour and depth).
249
250    Returns:
251        The model, a ``torch.nn.Module``.
252
253    Raises:
254        ValueError: If ``channels`` is not 3 or 4.
255    """
256    import torch
257    from torchvision.models import ResNet18_Weights, resnet18
258
259    net = resnet18(weights=ResNet18_Weights.IMAGENET1K_V1 if pretrained else None)
260    if channels == 4:
261        old = net.conv1
262        net.conv1 = torch.nn.Conv2d(4, old.out_channels, old.kernel_size, old.stride, old.padding, bias=False)
263        with torch.no_grad():
264            net.conv1.weight[:, :3] = old.weight
265            net.conv1.weight[:, 3] = old.weight.mean(dim=1)
266    elif channels != 3:
267        raise ValueError(f"channels must be 3 or 4, got {channels}")
268    net.fc = torch.nn.Linear(net.fc.in_features, n_out)
269    torch.nn.init.normal_(net.fc.weight, std=0.01)
270    torch.nn.init.zeros_(net.fc.bias)
271    return net

279def predict(model, x_uint8, mirror: tuple, batch: int = 32) -> np.ndarray:
280    """Standardised predictions, each the average of the photo's and its mirror image's.
281
282    Args:
283        model: The network.
284        x_uint8: ``(N, 3, H, W)`` uint8 tensor on the model's device.
285        mirror: ``(src, sign)`` from :func:`mirror_columns`, as tensors on
286            the same device.
287        batch: Photos per forward pass.
288
289    Returns:
290        ``(N, k)`` array.
291    """
292    import torch
293
294    src, sign = mirror
295    model.eval()
296    out = []
297    with torch.inference_mode():
298        for i in range(0, len(x_uint8), batch):
299            x = normalise(_as_float(x_uint8[i:i + batch]))
300            out.append(((model(x) + model(x.flip(-1))[:, src] * sign) / 2).float().cpu().numpy())
301    return np.concatenate(out) if out else np.zeros((0, len(src)))

304def train(model, x_uint8, z: np.ndarray, epochs: int, params: CNNParams, mirror, seed: int,
305          val: tuple | None = None, on_epoch: Callable[[dict], None] | None = None) -> list[dict]:
306    """Train ``model`` in place: AdamW with a cosine learning-rate decay over ``epochs``.
307
308    Args:
309        model: The network, on its device.
310        x_uint8: ``(N, 3, H, W)`` uint8 tensor of training photos on the device.
311        z: ``(N, k)`` standardised targets (NaN = unknown).
312        epochs: Epochs to train.
313        params: The recipe.
314        mirror: ``(src, sign)`` from :func:`mirror_columns`, as tensors on the device.
315        seed: Seed for the batch order and the augmentation.
316        val: Optional ``(x_uint8, z)`` held out; its loss (with the mirror
317            averaging of :func:`predict`) is recorded after each epoch.
318        on_epoch: Called with each epoch's record.
319
320    Returns:
321        One record per epoch: ``{"epoch", "train_loss", "val_loss"}``.
322    """
323    import torch
324
325    dev = x_uint8.device
326    torch.manual_seed(seed)
327    gen = torch.Generator(device=dev).manual_seed(seed)
328    target = torch.as_tensor(z, dtype=torch.float32, device=dev)
329    head = list(model.fc.parameters())
330    body = [p for n, p in model.named_parameters() if not n.startswith("fc.")]
331    opt = torch.optim.AdamW([{"params": body, "lr": params.lr_backbone}, {"params": head, "lr": params.lr_head}],
332                            weight_decay=params.weight_decay)
333    n = len(x_uint8)
334    steps = max(1, math.ceil(n / params.batch)) * max(1, epochs)
335    sched = torch.optim.lr_scheduler.LambdaLR(opt, lambda step: 0.5 * (1 + math.cos(math.pi * min(step, steps) / steps)))
336    log = []
337    for epoch in range(1, epochs + 1):
338        model.train()
339        order = torch.randperm(n, device=dev, generator=gen)
340        total, count = 0.0, 0
341        for i in range(0, n, params.batch):
342            idx = order[i:i + params.batch]
343            if len(idx) < 2:                                   # batch norm needs two photos
344                continue
345            x, flipped = augment(_as_float(x_uint8[idx]), gen, params)
346            t = target[idx]
347            t = torch.where(flipped.unsqueeze(1), t[:, mirror[0]] * mirror[1], t)   # an unknown stays in its place
348            loss = masked_mse(model(x), t)
349            opt.zero_grad(set_to_none=True)
350            loss.backward()
351            opt.step()
352            sched.step()
353            total, count = total + loss.item() * len(idx), count + len(idx)
354        record = {"epoch": epoch, "train_loss": total / max(count, 1), "val_loss": None}
355        if val is not None:
356            pv = torch.as_tensor(predict(model, val[0], mirror), device=dev)
357            record["val_loss"] = float(masked_mse(pv, torch.as_tensor(val[1], dtype=torch.float32, device=dev)))
358        log.append(record)
359        if on_epoch:
360            on_epoch(record)
361    return log

364def _inner_rows(i: int, fold_rows: Sequence[Sequence[int]], train_rows: set[int], rows: np.ndarray) -> list[int] | None:
365    """The first following fold whose rows leave at least two training trees and hold at least one (or None)."""
366    k = len(fold_rows)
367    for step in range(1, k):
368        cand = [r for r in fold_rows[(i + step) % k] if r in train_rows]
369        held = np.isin(rows, cand)
370        if held.any() and (np.isin(rows, list(train_rows)) & ~held).sum() >= 2:
371            return cand
372    return None

380def cross_validate_cnn(images: np.ndarray, y: np.ndarray, rows: np.ndarray, fold_rows: Sequence[Sequence[int]],
381                       params: CNNParams = CNNParams(), device: str | None = None, pretrained: bool = True,
382                       names: Sequence[str] = MEASURES, progress: Callable[[str], None] = print) -> dict:
383    """Fine-tune and predict every tree from the fold that holds its row out (see the module docstring).
384
385    Args:
386        images: ``(n, H, W, 3)`` uint8 summer photos, already at ``params.size``
387            (``(n, H, W, 4)`` with the depth last, for ``params.depth``).
388        y: ``(n, k)`` winter measures (NaN = unknown).
389        rows: ``(n,)`` orchard rows.
390        fold_rows: Each fold's held-out rows (``splits.json``).
391        params: The recipe.
392        device: ``"cuda"``, ``"cpu"``, or None for the GPU if there is one.
393        pretrained: Start from the ImageNet weights (False: random, for tests).
394        names: The measures of ``y``'s columns.
395        progress: Where progress lines go.
396
397    Returns:
398        ``{"cnn": (n, k), "mean": (n, k), "fold": (n,), "epochs": [...], "log": [...], "device": str}``.
399    """
400    import torch
401
402    device = device or ("cuda" if torch.cuda.is_available() else "cpu")
403    torch.manual_seed(params.seed)                          # the new output layer's first weights
404    base = make_model(len(names), pretrained, channels=images.shape[3]).to(device)
405    start = copy.deepcopy(base.state_dict())
406    # A mirrored photo has mirrored measures: left and right swap, and signed angles change sign.
407    src, sign = mirror_columns(names)
408    mirror = (torch.as_tensor(src, device=device), torch.as_tensor(sign, dtype=torch.float32, device=device))
409    x_all = torch.from_numpy(np.ascontiguousarray(images.transpose(0, 3, 1, 2))).to(device)
410    n = len(y)
411    pred, mean, fold = np.full((n, len(names)), np.nan), np.full((n, len(names)), np.nan), np.full(n, -1)
412    chosen, logs = [], []
413
414    def fresh():
415        """The network reset to its starting weights (one copy reused, to save memory)."""
416        base.load_state_dict(start)
417        return base
418
419    for i, held in enumerate(fold_rows):
420        # This fold's rows are predicted; the network trains on the other rows.
421        va = np.isin(rows, list(held))
422        tr = ~va
423        if not va.any() or tr.sum() < 2:
424            continue
425        t0 = time.time()
426        # The number of epochs is chosen inside the training rows: the next fold's rows are held out, and the
427        # epoch with the lowest loss on them is kept. The fold's own rows play no part in the choice.
428        train_rows = set(rows[tr].tolist())
429        inner = _inner_rows(i, fold_rows, train_rows, rows)
430        best = params.epochs
431        if inner is not None:
432            iv = tr & np.isin(rows, inner)
433            it = tr & ~iv
434            # The measures are standardised with the training trees' own mean and spread.
435            mu, s = target_scale(y[it], names)
436            z = (y - mu) / s
437            progress(f"Fold {i + 1}/{len(fold_rows)} (rows {sorted(map(int, held))}, {_n(va.sum(), 'tree')}): "
438                     f"choosing the epochs on rows {sorted(map(int, inner))} ({_n(iv.sum(), 'tree')})...")
439            log = train(fresh(), x_all[torch.from_numpy(np.nonzero(it)[0]).to(device)], z[it], params.epochs, params,
440                        mirror, params.seed + 100 * i, val=(x_all[torch.from_numpy(np.nonzero(iv)[0]).to(device)], z[iv]),
441                        on_epoch=lambda r: (progress(f"  epoch {r['epoch']:3d}: train {r['train_loss']:.3f}, "
442                                                     f"held out {r['val_loss']:.3f}")
443                                            if r["epoch"] % 5 == 0 or r["epoch"] == 1 else None))
444            logs += [{"fold": i, "stage": "choose", **r} for r in log]
445            best = int(min(log, key=lambda r: r["val_loss"])["epoch"])
446            progress(f"  lowest held-out loss after {_n(best, 'epoch')}")
447        else:
448            progress(f"Fold {i + 1}/{len(fold_rows)}: no rows to hold out inside the training rows; "
449                     f"training for {_n(best, 'epoch')}")
450        # Then a fresh network trains on all the training rows for that many epochs and predicts the fold.
451        mu, s = target_scale(y[tr], names)
452        z = (y - mu) / s
453        idx = torch.from_numpy(np.nonzero(tr)[0]).to(device)
454        log = train(fresh(), x_all[idx], z[tr], best, params, mirror, params.seed + 100 * i + 50)
455        logs += [{"fold": i, "stage": "final", **r} for r in log]
456        zp = predict(base, x_all[torch.from_numpy(np.nonzero(va)[0]).to(device)], mirror)
457        pred[va] = mu + s * zp                              # back from standardised units to degrees
458        # The baseline: the training trees' mean shape (a measure unknown on every tree stays NaN).
459        with warnings.catch_warnings():
460            warnings.simplefilter("ignore", RuntimeWarning)
461            mean[va] = np.nanmean(y[tr], axis=0)
462        fold[va] = i
463        chosen.append({"fold": i, "epochs": best, "inner_rows": inner, "seconds": round(time.time() - t0, 1)})
464        progress(f"  trained on {_n(tr.sum(), 'tree')} for {_n(best, 'epoch')}; fold done in {time.time() - t0:.0f} s")
465    return {"cnn": pred, "mean": mean, "fold": fold, "epochs": chosen, "log": logs, "device": device}

468def load_photos(records: dict, ids: Sequence[str], size: tuple[int, int], progress: Callable[[str], None] = print,
469                depth: bool = False) -> np.ndarray:
470    """The summer photos of ``ids``, resized (bilinear) to ``size`` = ``(height, width)``.
471
472    Args:
473        records: Tree records by id.
474        ids: The trees to load.
475        size: ``(height, width)``.
476        progress: Prints a progress line.
477        depth: Add the summer depth as a fourth channel.
478
479    Returns:
480        ``(n, H, W, 3)`` uint8, or ``(n, H, W, 4)`` with the summer depth last if ``depth``.
481    """
482    from PIL import Image
483
484    from treeskel.io import load_tree
485
486    out = np.zeros((len(ids), size[0], size[1], 4 if depth else 3), np.uint8)
487    step = max(1, len(ids) // 10)
488    for i, t in enumerate(ids):
489        summer = load_tree(records[t], "summer")
490        out[i, ..., :3] = np.asarray(Image.fromarray(summer["rgb"]).resize(size[::-1], Image.BILINEAR))
491        if depth:
492            out[i, ..., 3] = np.asarray(Image.fromarray(summer["depth"]).resize(size[::-1], Image.BILINEAR))
493        if (i + 1) % step == 0 or i + 1 == len(ids):
494            progress(f"  {i + 1}/{len(ids)} photos loaded")
495    return out

657def compare_runs(dirs: Sequence[Path], names: Sequence[str] = MEASURES) -> dict:
658    """Each run against the first, tree by tree, on the same trees and folds.
659
660    The folds' skills swing a lot (the V opening's from −0.15 to +0.44 in one
661    run), so differences between runs are judged tree by tree: the fraction
662    of trees a run predicts more closely than the first, a Wilcoxon
663    signed-rank test on the paired absolute errors, and the number of folds
664    whose skill rose.
665
666    Args:
667        dirs: Results folders (``predictions.csv`` and ``report.json`` each);
668            the first is the reference.
669        names: The measures.
670
671    Returns:
672        ``{run: {measure: {"skill", "reference_skill", "closer", "wilcoxon_p",
673        "folds_better", "n_folds"}}}`` for every run after the first.
674    """
675    from scipy import stats
676
677    def load(d):
678        """A run's ``{(tree, measure): (winter, predicted)}`` and its report."""
679        rows = {}
680        with open(Path(d) / "predictions.csv", newline="") as f:
681            for r in csv.DictReader(f):
682                if r["winter"] and r["cnn fine-tuned"]:
683                    rows[(r["tree"], r["measure"])] = (float(r["winter"]), float(r["cnn fine-tuned"]))
684        return rows, json.loads((Path(d) / "report.json").read_text())
685
686    ref, ref_report = load(dirs[0])
687    out = {}
688    for d in dirs[1:]:
689        run, report = load(d)
690        out[Path(d).name] = {}
691        for k in names:
692            keys = [key for key in ref if key[1] == k and key in run]
693            if len(keys) < 3:
694                continue
695            e0 = np.array([abs(ref[key][1] - ref[key][0]) for key in keys])
696            e1 = np.array([abs(run[key][1] - run[key][0]) for key in keys])
697            diff = e0 - e1
698            f0 = ref_report["scores"][k]["cnn fine-tuned"].get("fold_skill", [])
699            f1 = report["scores"][k]["cnn fine-tuned"].get("fold_skill", [])
700            pairs = [(a, b) for a, b in zip(f0, f1) if a is not None and b is not None]
701            out[Path(d).name][k] = {
702                "skill": report["scores"][k]["cnn fine-tuned"]["skill"],
703                "reference_skill": ref_report["scores"][k]["cnn fine-tuned"]["skill"],
704                "closer": float(np.mean(diff > 0)),
705                "wilcoxon_p": float(stats.wilcoxon(diff).pvalue) if np.any(diff != 0) else 1.0,
706                "folds_better": int(sum(b > a for a, b in pairs)), "n_folds": len(pairs)}
707    return out

710def print_comparison(comparison: dict, reference: str) -> None:
711    """Print :func:`compare_runs`'s result.
712
713    Args:
714        comparison: From :func:`compare_runs`.
715        reference: The run the others are compared with.
716    """
717    for run, measures in comparison.items():

726    """The figures from saved results: a comparison of every run in ``dirs`` and each run's learning curves.

728    Args:

753def main(argv: Sequence[str] | None = None) -> int:
754    """Fine-tune on the development rows, fold by fold, and save the scores (or, with ``--replot``, only redraw
755    the figures from saved results).
756
757    Args:
758        argv: Command-line arguments; ``None`` reads ``sys.argv[1:]``.
759

762        is missing, the GPU ran out of memory, or an output file could not be written.

771    ap.add_argument("--device", help="cuda or cpu (default: the GPU if there is one)")

776                    help="photos per training step (smaller if the GPU runs out of memory; recorded in the report)")
777    ap.add_argument("--seed", type=int, default=CNNParams.seed)
778    ap.add_argument("--replot", nargs="+", metavar="DIR",
779                    help="only redraw the figures from these results folders (and compare them with the first)")

794            print(f"Could not write {f}")
795        return 1 if failed else 0

797        ap.error("give the dataset folder(s), or --replot")

800
801    params = CNNParams(size=tuple(args.size), epochs=args.epochs, seed=args.seed, depth=args.depth, batch=args.batch)
802    split = json.loads(Path(args.split).read_text())
803    test_rows = set(split["test_rows"])
804    table = load_table(args.table)
805    if any(r["row"] in test_rows for r in table):
806        print("The table holds test-row trees; they are never used here. Stopping.")
807        return 1
808    records = {t.tree_id: t for d in args.data_dirs for t in index_dataset(d).trees}
809    by_id = {r["tree"]: r for r in table}
810    trees = sorted(t for t in by_id if t in records)
811    if len(trees) < 3:
812        print(f"Only {len(trees)} trees have both measures and photos; nothing to train.")
813        return 1
814    try:
815        import torch  # noqa: F401
816        import torchvision  # noqa: F401
817    except ImportError as e:
818        print(f"PyTorch and torchvision are needed: {e}")
819        return 1
820    what = "photos and depth" if params.depth else "photos"
821    print(f"{len(trees)} development trees; loading the summer {what} at {params.size[0]}x{params.size[1]}...",
822          flush=True)
823    images = load_photos(records, trees, params.size, lambda m: print(m, flush=True), depth=params.depth)
824    rows = np.array([by_id[t]["row"] for t in trees])
825    y = np.array([[by_id[t][f"winter_{k}"] for k in MEASURES] for t in trees], float)
826    hand = np.array([[by_id[t][f"hand_{k}"] for k in MEASURES] for t in trees], float)

828    try:
829        cv = cross_validate_cnn(images, y, rows, split["fold_val_rows"], params, args.device,
830                                pretrained=not args.random_weights, progress=lambda m: print(m, flush=True))
831    except (OSError, RuntimeError) as e:                   # a failed weights download, or out of GPU memory
832        print(f"Training stopped: {type(e).__name__}: {e}\nIf the weights could not be downloaded, see the note "
833              "printed by python -m treeskel.shape when that happens (the file resnet18-f37072fd.pth). If the GPU ran "
834              "out of memory, close other programs using it (nvidia-smi lists them) and try again, or add --batch 8.")
835        return 1
836    ridge = _ridge_predictions(Path(args.ridge), trees, MEASURES)
837    report = {"n_trees": len(trees), "variant": variant(params), "params": asdict(params), "device": cv["device"],
838              "weights": "random" if args.random_weights else "IMAGENET1K_V1", "epochs": cv["epochs"],
839              "minutes": round((time.time() - t0) / 60, 1), "scores": {}}
840    for j, k in enumerate(MEASURES):
841        base = cv["mean"][:, j]
842        mean_shape = evaluate(y[:, j], base, base, cv["fold"])
843        mean_shape["r"] = None
844        sc = {"mean shape": mean_shape, "hand masks": evaluate(y[:, j], hand[:, j], base, cv["fold"]),
845              "cnn fine-tuned": evaluate(y[:, j], cv["cnn"][:, j], base, cv["fold"])}
846        if ridge is not None:
847            sc["ridge rgb"] = evaluate(y[:, j], ridge[:, j], base, cv["fold"])
848        report["scores"][k] = sc
849    for title, names in (("Headline (no reference direction)", HEADLINE), ("From the trunk's axis", TRUNK_RELATIVE),
850                         ("From the photo's vertical (camera roll adds to these)", VERTICAL)):
851        print(f"\n{title}:")
852        print_scores(report, names)
853    out = Path(args.out or f"docs/results/{variant(params)}")
854    out.mkdir(parents=True, exist_ok=True)
855    (out / "report.json").write_text(json.dumps(report, indent=2))
856    with open(out / "predictions.csv", "w", newline="") as f:
857        w = csv.writer(f)
858        w.writerow(["tree", "row", "fold", "measure", "winter", "mean shape", "hand masks", "cnn fine-tuned"])
859        for i, t in enumerate(trees):
860            for j, k in enumerate(MEASURES):
861                w.writerow([t, int(rows[i]), int(cv["fold"][i]), k]
862                           + ["" if not np.isfinite(v) else f"{v:.2f}"
863                              for v in (y[i, j], cv["mean"][i, j], hand[i, j], cv["cnn"][i, j])])
864    with open(out / "training_log.csv", "w", newline="") as f:
865        w = csv.DictWriter(f, fieldnames=["fold", "stage", "epoch", "train_loss", "val_loss"])

def augment( x, generator, params: CNNParams = CNNParams(size=(240, 320), epochs=40, batch=16, lr_backbone=0.0001, lr_head=0.001, weight_decay=0.0001, crop=0.8, jitter=0.2, seed=0, depth=False), flip_p: float = 0.5): 
191def augment(x, generator, params: CNNParams = CNNParams(), flip_p: float = 0.5):
192    """Random crop, mirror image and colour jitter for a batch of photos.
193
194    The crop and the mirror are one affine resampling per photo: a square
195    fraction ``f`` of each side (``f² ∈ [crop, 1]`` of the area) at a random
196    position, with the x axis reversed for a mirror image.
197
198    Args:
199        x: ``(B, 3, H, W)`` floats in [0, 1], or ``(B, 4, H, W)`` with the
200            depth last (cropped and mirrored with the photo, but not jittered).
201        generator: A ``torch.Generator`` on ``x``'s device, for repeatable runs.
202        params: ``crop`` and ``jitter``.
203        flip_p: Chance of the mirror image.
204
205    Returns:
206        ``(images, flipped)``: normalised images of ``x``'s shape and a
207        ``(B,)`` bool tensor, True where the mirror image was taken.
208    """
209    import torch
210    import torch.nn.functional as F
211
212    b, dev = x.shape[0], x.device
213
214    def uniform(lo, hi):
215        """``b`` random numbers between ``lo`` and ``hi``, one per image."""
216        return lo + (hi - lo) * torch.rand(b, device=dev, generator=generator)
217
218    f = torch.sqrt(uniform(params.crop, 1.0))                    # side fraction
219    tx, ty = uniform(-1.0, 1.0) * (1 - f), uniform(-1.0, 1.0) * (1 - f)
220    flipped = torch.rand(b, device=dev, generator=generator) < flip_p
221    sx = torch.where(flipped, -f, f)
222    theta = torch.zeros(b, 2, 3, device=dev)
223    theta[:, 0, 0], theta[:, 0, 2], theta[:, 1, 1], theta[:, 1, 2] = sx, tx, f, ty
224    grid = F.affine_grid(theta, list(x.shape), align_corners=False)
225    x = F.grid_sample(x, grid, mode="bilinear", padding_mode="border", align_corners=False)
226    j = params.jitter
227    if j > 0:
228        rgb, rest = x[:, :3], x[:, 3:]                                          # depth is not jittered
229        rgb = rgb * uniform(1 - j, 1 + j).view(b, 1, 1, 1)                     # brightness
230        mean = rgb.mean(dim=(1, 2, 3), keepdim=True)
231        rgb = (rgb - mean) * uniform(1 - j, 1 + j).view(b, 1, 1, 1) + mean      # contrast
232        grey = (0.299 * rgb[:, 0] + 0.587 * rgb[:, 1] + 0.114 * rgb[:, 2]).unsqueeze(1)
233        rgb = grey + (rgb - grey) * uniform(1 - j, 1 + j).view(b, 1, 1, 1)      # saturation
234        x = torch.cat([rgb.clamp(0, 1), rest], dim=1)
235    return normalise(x), flipped

658def compare_runs(dirs: Sequence[Path], names: Sequence[str] = MEASURES) -> dict:
659    """Each run against the first, tree by tree, on the same trees and folds.
660
661    The folds' skills swing a lot (the V opening's from −0.15 to +0.44 in one
662    run), so differences between runs are judged tree by tree: the fraction
663    of trees a run predicts more closely than the first, a Wilcoxon
664    signed-rank test on the paired absolute errors, and the number of folds
665    whose skill rose.
666
667    Args:
668        dirs: Results folders (``predictions.csv`` and ``report.json`` each);
669            the first is the reference.
670        names: The measures.
671
672    Returns:
673        ``{run: {measure: {"skill", "reference_skill", "closer", "wilcoxon_p",
674        "folds_better", "n_folds"}}}`` for every run after the first.
675    """
676    from scipy import stats
677
678    def load(d):
679        """A run's ``{(tree, measure): (winter, predicted)}`` and its report."""
680        rows = {}
681        with open(Path(d) / "predictions.csv", newline="") as f:
682            for r in csv.DictReader(f):
683                if r["winter"] and r["cnn fine-tuned"]:
684                    rows[(r["tree"], r["measure"])] = (float(r["winter"]), float(r["cnn fine-tuned"]))
685        return rows, json.loads((Path(d) / "report.json").read_text())
686
687    ref, ref_report = load(dirs[0])
688    out = {}
689    for d in dirs[1:]:
690        run, report = load(d)
691        out[Path(d).name] = {}
692        for k in names:
693            keys = [key for key in ref if key[1] == k and key in run]
694            if len(keys) < 3:
695                continue
696            e0 = np.array([abs(ref[key][1] - ref[key][0]) for key in keys])
697            e1 = np.array([abs(run[key][1] - run[key][0]) for key in keys])
698            diff = e0 - e1
699            f0 = ref_report["scores"][k]["cnn fine-tuned"].get("fold_skill", [])
700            f1 = report["scores"][k]["cnn fine-tuned"].get("fold_skill", [])
701            pairs = [(a, b) for a, b in zip(f0, f1) if a is not None and b is not None]
702            out[Path(d).name][k] = {
703                "skill": report["scores"][k]["cnn fine-tuned"]["skill"],
704                "reference_skill": ref_report["scores"][k]["cnn fine-tuned"]["skill"],
705                "closer": float(np.mean(diff > 0)),
706                "wilcoxon_p": float(stats.wilcoxon(diff).pvalue) if np.any(diff != 0) else 1.0,
707                "folds_better": int(sum(b > a for a, b in pairs)), "n_folds": len(pairs)}
