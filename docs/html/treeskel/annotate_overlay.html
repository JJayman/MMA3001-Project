treeskel.annotate_overlay

Overlay tool: line up each tree's winter photo on its summer photo by hand.

Clicking exactly the same point in both seasons was slow (about 2 minutes a tree) and still about 10 px off (session 7, docs/results/align/): in summer the leaves hide most of the tree, and the two photos are framed differently, so few points can be matched for certain. Lining up the whole photos is easier: the trunk, the posts, the drip line and the ground line must all sit on top of each other at once.

Run on your own computer (it opens a window)::

python -m treeskel.annotate_overlay data/raw --trees R01N01 R01N02

The summer photo is shown with the winter photo on top, half see-through, moved by the current transform (treeskel.summer_gt.Overlay). Move the winter photo until the two line up:

  • drag (left mouse button): shift it;
  • scroll: make it bigger or smaller around the cursor;
  • arrow keys: shift by 1 px (with shift: 10 px);
  • [ and ]: rotate (roll) by 0.2° ({ and }: 1°);
  • - and =: scale by 0.5%;
  • i and k: tilt up and down (pitch) by 0.5°: one end of the photo gets wider than the other;
  • j and l: tilt left and right (yaw) by 0.5°.

Keyboard scaling, rolling and tilting keep the tree's fork where it is, so fine-tuning does not undo a lined-up trunk. To judge the fit:

  • space: flip between the winter and the summer photo. What is lined up stays still; what is not jumps;
  • b: back to the blend (30% winter to start); 1–9: blend from 10% to 90% winter;
  • e: the summer photo at full strength, with the outlines of what the winter depth camera saw (the tree, posts, neighbouring trunks) in cyan. Line those up with the summer posts and trunk; the drip line is not in depth, so check it in the blend;
  • m: show or hide the winter mask (magenta).

A good order: drag until the trunk sits on the summer trunk; then match the posts and the drip line with scale and roll; use the tilts only if the top and the bottom still disagree. Leaves hide the leaders in summer, so match what both photos show.

Other keys:

======== ========================================================== Enter accept this tree and go to the next u undo the last change r reset to the starting transform s skip this tree (cannot be aligned); it gets no summer mask f flag this tree's winter mask as wrong (off the branch, wrong width), to be fixed later; press again to unflag n / p next / previous tree without saving q save and quit ======== ==========================================================

Each tree starts from the median transform of the trees already aligned in its row (the camera was handled alike within a row), or of all aligned trees, so often only a small nudge is needed. The transforms are saved to annotations/season_overlay.json after every tree, with the time spent on it. The toolbar's zoom works as usual: drags made while zoom or pan is switched on are ignored. --redo shows trees already aligned, starting from their saved transform.

The current tree, its transform and whether its mask is flagged are shown in the window's title bar. Each change takes about 60 ms on a 4-core machine (the first version took about 400 ms). The time grows with the window's size in pixels, so if it lags, make the window smaller.

 95def median_overlay(overlays: Sequence[Overlay]) -> Overlay:
 96    """Parameter-wise median of some transforms (the identity if there are none)."""
 97    if not overlays:
 98        return Overlay()
 99    return Overlay(**{k: float(np.median([getattr(o, k) for o in overlays])) for k in Overlay.PARAMS})

102def depth_silhouette(depth: np.ndarray, valid: np.ndarray, min_area: int = 150) -> np.ndarray:
103    """What the winter depth camera separates from the ground: the tree, posts, neighbouring trunks.
104
105    The depth foreground (:func:`treeskel.winter_gt.foreground_mask`; the rows
106    behind are out of range in winter), opened by one pixel, without pieces
107    smaller than ``min_area`` px. Its outline is much cleaner than edges in
108    the colour photo, where grass and the rows behind give edges everywhere.
109    """
110    fg = ndi.binary_opening(foreground_mask(depth, valid), iterations=1)
111    lab, n = ndi.label(fg)
112    sizes = np.bincount(lab.ravel(), minlength=n + 1)
113    keep = sizes >= min_area
114    keep[0] = False
115    return keep[lab]

121def fast_warp(image: np.ndarray, matrix: np.ndarray, nearest: bool = False,
122              out_size: tuple[int, int] = (640, 480)) -> np.ndarray:
123    """Warp an image by a winter-to-summer transform with Pillow's compiled perspective warp.
124
125    About 10 times faster than :func:`treeskel.align.warp_image`, for the live
126    display. Pillow maps each output pixel back into the input with pixel
127    centres at +0.5, so the transform is shifted by half a pixel either side;
128    the result then matches :func:`treeskel.align.warp_mask` exactly for masks
129    (``nearest=True``) and :func:`treeskel.align.warp_image` to within about
130    one grey level. Pixels outside the input are 0 (transparent for RGBA).
131
132    Args:
133        image: ``uint8`` image, ``(H, W)``, ``(H, W, 3)`` or ``(H, W, 4)``.
134        matrix: 3x3 winter-to-summer ``(x, y)`` transform.
135        nearest: Nearest-neighbour instead of bilinear sampling.
136        out_size: Output ``(width, height)``.
137    """
138    inv = _HALF @ np.linalg.inv(matrix) @ np.linalg.inv(_HALF)
139    inv = inv / inv[2, 2]
140    resample = Image.Resampling.NEAREST if nearest else Image.Resampling.BILINEAR
141    return np.asarray(Image.fromarray(image).transform(out_size, Image.Transform.PERSPECTIVE,
142                                                       tuple(inv.ravel()[:8]), resample))

145class OverlayAnnotator:
146    """State and event handling for the overlay tool, independent of display.
147
148    Args:
149        trees: Trees to align, in order.
150        path: JSON file to read and write.
151        redo: Also show trees already aligned (starting from their transform).
152        clicks_path: Winter clicks, for the fork (the pin point) and to trace
153            a tree's mask if it is not in ``gt_dir``.
154        gt_dir: Folder of ``<tree>_winter_gt.png`` masks.
155        clock: Time source in seconds (for tests).
156    """
157
158    def __init__(self, trees: Sequence[TreeRecord], path: str | Path, redo: bool = False,
159                 clicks_path: str | Path = "annotations/winter_clicks.json",
160                 gt_dir: str | Path | None = "outputs/winter_gt_guided",
161                 clock: Callable[[], float] = time.monotonic):
162        """Load the saved transforms and the winter clicks, and open the first tree still to align."""
163        self.path = path
164        self.saved = load_overlays(path)
165        self.trees = [t for t in trees if redo or t.tree_id not in self.saved]
166        self.winter_clicks = load_clicks(clicks_path)
167        self.gt_dir = Path(gt_dir) if gt_dir else None
168        self.clock = clock
169        self.i = 0
170        self.view = "blend"             # "blend", "winter", "summer" or "outlines"
171        self.alpha = 0.3                # the winter photo is brighter and busier: keep summer visible
172        self.show_mask = True
173        self.done = False
174        self._load()
175
176    # --- current tree -------------------------------------------------------
177    @property
178    def tree(self) -> TreeRecord | None:
179        """The tree being aligned, or ``None`` once every tree is done."""
180        return self.trees[self.i] if self.i < len(self.trees) else None
181
182    def start(self) -> Overlay:
183        """Starting transform: the saved one, else the median of the row's trees, else of all trees."""
184        tid = self.tree.tree_id
185        old = self.saved.get(tid)
186        if old is not None and not old.skip:
187            return replace(old)
188        done = [o for t, o in self.saved.items() if not o.skip and t != tid]
189        row = [o for t, o in self.saved.items() if not o.skip and t != tid and t[:3] == tid[:3]]
190        return median_overlay(row if len(row) >= 2 else done)
191
192    def _load(self) -> None:
193        """Load the current tree's images, mask and pin point, and its starting transform."""
194        self.history: list[Overlay] = []
195        if self.tree is None:
196            self.done = True
197            return
198        tid = self.tree.tree_id
199        self.winter = load_tree(self.tree, "winter")
200        self.summer = load_tree(self.tree, "summer")
201        self.mask = load_winter_mask(tid, self.winter, self.winter_clicks, self.gt_dir)
202        # Warped on every change, so prepared once: the photo with full opacity, and the mask's outline.
203        self._rgba = np.dstack([self.winter["rgb"], np.full(self.winter["rgb"].shape[:2], 255, np.uint8)])
204        self._outline = outline(self.mask, 2).astype(np.uint8) * 255 if self.mask is not None else None
205        self._depth_outline = outline(depth_silhouette(self.winter["depth"], self.winter["valid"]),
206                                      1).astype(np.uint8) * 255
207        c = self.winter_clicks.get(tid)
208        self.pin = np.array(c.fork[::-1], float) if c is not None and c.complete and not c.skip \
209            else np.array([320.0, 240.0])
210        self.initial = self.start()
211        self.ov = replace(self.initial)
212        old = self.saved.get(tid)
213        self.flag = bool(old.mask_flag) if old is not None else False
214        self.spent_before = old.seconds if old is not None else 0.0
215        self.t0 = self.clock()
216
217    # --- the transform ------------------------------------------------------
218    def matrix(self) -> np.ndarray:
219        """The current winter-to-summer transform."""
220        return self.ov.matrix()
221
222    def composite(self) -> np.ndarray:
223        """The picture to show: the summer photo with the moved winter photo and mask on top.
224
225        In the ``"blend"`` view the winter photo covers the summer one at
226        ``alpha``, in ``"winter"`` fully, and in ``"summer"`` not at all; the
227        part of the summer photo the winter one does not cover always shows
228        through. The ``"outlines"`` view shows the summer photo at full
229        strength with the outline of the winter depth silhouette
230        (:func:`depth_silhouette`) in cyan. The mask's outline is drawn in
231        magenta if ``show_mask``.
232        Blending here into one picture, rather than layering images in the
233        window, keeps each update fast.
234
235        Returns:
236            ``(480, 640, 3)`` uint8 image.
237        """
238        m = self.matrix()
239        a = {"blend": self.alpha, "winter": 1.0, "summer": 0.0, "outlines": 0.0}[self.view]
240        out = self.summer["rgb"]
241        if a > 0:
242            w = fast_warp(self._rgba, m).astype(np.float32)
243            k = w[..., 3:] * (a / 255.0)
244            out = (out * (1 - k) + w[..., :3] * k + 0.5).astype(np.uint8)
245        if self.view == "outlines":
246            line = fast_warp(self._depth_outline, m, nearest=True) > 0
247            out = out.copy()
248            out[line] = (0, 255, 255)
249        if self.show_mask and self._outline is not None:
250            line = fast_warp(self._outline, m, nearest=True) > 0
251            out = out.copy() if out is self.summer["rgb"] else out
252            out[line] = (255, 0, 255)
253        return out
254
255    def _change(self, pin_xy: np.ndarray | None = None, **params) -> None:
256        """Set some parameters, keeping the winter point ``pin_xy`` where it was in the summer view."""
257        self.history.append(replace(self.ov))
258        before = apply_transform(self.matrix(), [pin_xy])[0] if pin_xy is not None else None
259        for k, v in params.items():
260            setattr(self.ov, k, float(v))
261        if before is not None:
262            after = apply_transform(self.matrix(), [pin_xy])[0]
263            self.ov.dx += before[0] - after[0]
264            self.ov.dy += before[1] - after[1]
265
266    def shift(self, ddx: float, ddy: float) -> None:
267        """Move the winter photo by ``(ddx, ddy)`` px."""
268        self._change(dx=self.ov.dx + ddx, dy=self.ov.dy + ddy)
269
270    def rescale(self, factor: float, about: tuple[float, float] | None = None) -> None:
271        """Scale by ``factor``, keeping the summer point ``about`` (``(x, y)``) fixed, or the fork."""
272        q = self.pin if about is None else apply_transform(np.linalg.inv(self.matrix()), [about])[0]
273        self._change(pin_xy=q, scale=self.ov.scale * factor)
274
275    def rotate(self, degrees: float) -> None:
276        """Roll by ``degrees`` (clockwise), keeping the fork fixed."""
277        self._change(pin_xy=self.pin, roll=self.ov.roll + degrees)
278
279    def tilt(self, pitch: float = 0.0, yaw: float = 0.0) -> None:
280        """Add perspective (degrees), keeping the fork fixed."""
281        self._change(pin_xy=self.pin, pitch=self.ov.pitch + pitch, yaw=self.ov.yaw + yaw)
282
283    # --- events -------------------------------------------------------------
284    def prompt(self) -> str:
285        """Current tree, transform and help, for the window title."""
286        if self.done:
287            return "All trees done - press q to save and quit"
288        o = self.ov
289        spent = self.spent_before + self.clock() - self.t0
290        return (f"{self.tree.tree_id} ({self.i + 1}/{len(self.trees)})  {self.view}"
291                + (f" {int(100 * self.alpha)}%" if self.view == "blend" else "")
292                + ("  MASK FLAGGED" if self.flag else "") + f"  {spent:.0f} s\n"
293                f"shift {o.dx:+.1f}, {o.dy:+.1f} px   scale {o.scale:.3f}   roll {o.roll:+.1f}   "
294                f"pitch {o.pitch:+.1f}   yaw {o.yaw:+.1f} deg\n"
295                "drag shift, scroll scale, arrows, [ ] roll, - = scale, i k j l tilt, space flip, b blend, "
296                "e outlines, m mask | Enter accept, u undo, r reset, s skip, f flag mask, n/p, q quit")
297
298    def key(self, key: str) -> None:
299        """Handle a key press."""
300        if key == "q":
301            save_overlays(self.path, self.saved)
302            self.done = True
303            return
304        if self.done:
305            return
306        arrows = {"left": (-1, 0), "right": (1, 0), "up": (0, -1), "down": (0, 1)}
307        base = key.replace("shift+", "")
308        if base in arrows:
309            step = STEPS["shift_big"] if key.startswith("shift+") else STEPS["shift"]
310            self.shift(arrows[base][0] * step, arrows[base][1] * step)
311        elif key in ("[", "]", "{", "}"):
312            step = STEPS["roll_big"] if key in "{}" else STEPS["roll"]
313            self.rotate(-step if key in "[{" else step)
314        elif key in ("-", "=", "+"):
315            self.rescale(1 / STEPS["scale"] if key == "-" else STEPS["scale"])
316        elif key in ("i", "k"):
317            self.tilt(pitch=STEPS["tilt"] if key == "i" else -STEPS["tilt"])
318        elif key in ("j", "l"):
319            self.tilt(yaw=-STEPS["tilt"] if key == "j" else STEPS["tilt"])
320        elif key == " ":
321            self.view = "summer" if self.view == "winter" else "winter"
322        elif key == "b":
323            self.view = "blend"
324        elif key == "e":
325            self.view = "outlines"
326        elif key in tuple("123456789"):
327            self.view, self.alpha = "blend", int(key) / 10
328        elif key == "m":
329            self.show_mask = not self.show_mask
330        elif key == "f":
331            self.flag = not self.flag
332        elif key == "u" and self.history:
333            self.ov = self.history.pop()
334        elif key == "r":
335            self._change(**self.initial.params())
336        elif key == "enter":
337            self._save(replace(self.ov, skip=False))
338        elif key == "s":
339            self._save(Overlay(skip=True, note="skipped in the overlay tool"))
340        elif key in ("n", "p"):
341            self._next(1 if key == "n" else -1)
342
343    def _save(self, ov: Overlay) -> None:
344        ov.mask_flag = self.flag
345        ov.seconds = self.spent_before + self.clock() - self.t0
346        self.saved[self.tree.tree_id] = ov
347        save_overlays(self.path, self.saved)
348        self._next(1)
349
350    def _next(self, step: int) -> None:
351        self.i = min(max(self.i + step, 0), len(self.trees))
352        self._load()

361def run_gui(ann: OverlayAnnotator, show: bool = True, help_text: str = HELP):
362    """Open the window and connect mouse and keyboard events.
363
364    For speed, the window is drawn in full only when needed (a new tree, a
365    zoom, a resize) and cached without the picture; each change then only
366    draws :meth:`OverlayAnnotator.composite` over the cache ("blitting").
367    The current tree and transform go in the window's title bar, which the
368    system draws.
369
370    Args:
371        ann: The annotator (or another with the same interface, e.g.
372            :class:`treeskel.annotate_mask.MaskAnnotator`).
373        show: Block in ``plt.show()`` (False only for tests).
374        help_text: Key help shown above the picture.
375
376    Returns:
377        The matplotlib figure.
378    """
379    import matplotlib.pyplot as plt
380
381    for k in ("keymap.save", "keymap.quit", "keymap.back", "keymap.forward", "keymap.pan",
382              "keymap.xscale", "keymap.yscale", "keymap.fullscreen"):
383        plt.rcParams[k] = []                        # free the tool's keys (s, q, arrows, k, l, f, ...)
384    plt.rcParams["keymap.home"] = ["h", "home"]     # and r (reset); h still resets the zoom
385    fig, ax = plt.subplots(figsize=(10, 8.2))
386    fig.subplots_adjust(0.005, 0.005, 0.995, 0.93)
387    ax.set_axis_off()
388    fig.suptitle(help_text, fontsize=8)
389    picture = ax.imshow(np.zeros((480, 640, 3), np.uint8), interpolation="nearest", animated=True)
390    canvas = fig.canvas
391    st = {"tree": None, "drag": None, "bg": None}
392
393    def on_draw(ev) -> None:
394        """After a full draw: cache it (without the picture), then draw the picture on top."""
395        st["bg"] = canvas.copy_from_bbox(fig.bbox)
396        fig.draw_artist(picture)
397
398    def status() -> None:
399        """Show the prompt's first lines in the window's title bar."""
400        manager = getattr(canvas, "manager", None)
401        if manager is not None:
402            lines = ann.prompt().splitlines()
403            manager.set_window_title(lines[0] if ann.done else f"{lines[0]}   |   {lines[1]}")
404
405    def update() -> None:
406        """Redraw the picture: a full draw for a new tree, else only the picture (blitted, for speed)."""
407        status()
408        if ann.done:
409            picture.set_data(np.zeros((480, 640, 3), np.uint8))
410            canvas.draw_idle()
411            return
412        picture.set_data(ann.composite())
413        if st["tree"] != ann.tree.tree_id:          # a new tree: show all of it (a full draw)
414            ax.set_xlim(-0.5, 639.5)
415            ax.set_ylim(479.5, -0.5)
416            st["tree"] = ann.tree.tree_id
417            canvas.draw_idle()
418        elif st["bg"] is None:
419            canvas.draw_idle()
420        else:                                        # the same view: only the picture changes
421            canvas.restore_region(st["bg"])
422            fig.draw_artist(picture)
423            canvas.blit(fig.bbox)
424
425    def tool_active() -> bool:
426        """Whether the toolbar's zoom or pan is switched on (then clicks are not drags)."""
427        toolbar = getattr(canvas, "toolbar", None)
428        return toolbar is not None and bool(getattr(toolbar, "mode", ""))
429
430    def on_press(ev) -> None:
431        """Start a drag: remember where it started, and the shift for undo."""
432        if ann.done or ev.button != 1 or ev.inaxes is not ax or ev.xdata is None or tool_active():

473                     ("scroll_event", on_scroll), ("key_press_event", on_key)):

def depth_silhouette( depth: numpy.ndarray, valid: numpy.ndarray, min_area: int = 150) -> numpy.ndarray: 
103def depth_silhouette(depth: np.ndarray, valid: np.ndarray, min_area: int = 150) -> np.ndarray:
104    """What the winter depth camera separates from the ground: the tree, posts, neighbouring trunks.
105
106    The depth foreground (:func:`treeskel.winter_gt.foreground_mask`; the rows
107    behind are out of range in winter), opened by one pixel, without pieces
108    smaller than ``min_area`` px. Its outline is much cleaner than edges in
109    the colour photo, where grass and the rows behind give edges everywhere.
110    """

112    lab, n = ndi.label(fg)
113    sizes = np.bincount(lab.ravel(), minlength=n + 1)
114    keep = sizes >= min_area
115    keep[0] = False
116    return keep[lab]

def fast_warp( image: numpy.ndarray, matrix: numpy.ndarray, nearest: bool = False, out_size: tuple[int, int] = (640, 480)) -> numpy.ndarray: 
122def fast_warp(image: np.ndarray, matrix: np.ndarray, nearest: bool = False,
123              out_size: tuple[int, int] = (640, 480)) -> np.ndarray:
124    """Warp an image by a winter-to-summer transform with Pillow's compiled perspective warp.
125
126    About 10 times faster than :func:`treeskel.align.warp_image`, for the live
127    display. Pillow maps each output pixel back into the input with pixel
128    centres at +0.5, so the transform is shifted by half a pixel either side;
129    the result then matches :func:`treeskel.align.warp_mask` exactly for masks
130    (``nearest=True``) and :func:`treeskel.align.warp_image` to within about
131    one grey level. Pixels outside the input are 0 (transparent for RGBA).
132
133    Args:
134        image: ``uint8`` image, ``(H, W)``, ``(H, W, 3)`` or ``(H, W, 4)``.
135        matrix: 3x3 winter-to-summer ``(x, y)`` transform.
136        nearest: Nearest-neighbour instead of bilinear sampling.
137        out_size: Output ``(width, height)``.
138    """
139    inv = _HALF @ np.linalg.inv(matrix) @ np.linalg.inv(_HALF)
140    inv = inv / inv[2, 2]
141    resample = Image.Resampling.NEAREST if nearest else Image.Resampling.BILINEAR
142    return np.asarray(Image.fromarray(image).transform(out_size, Image.Transform.PERSPECTIVE,
143                                                       tuple(inv.ravel()[:8]), resample))

def run_gui( ann: OverlayAnnotator, show: bool = True, help_text: str = 'drag: shift scroll: scale arrows: 1 px (shift: 10) [ ]: roll - =: scale i k j l: tilt space: flip b, 1-9: blend e: outlines m: mask\nEnter: accept u: undo r: reset s: skip f: flag the winter mask n / p: next / previous q: quit'): 
362def run_gui(ann: OverlayAnnotator, show: bool = True, help_text: str = HELP):
363    """Open the window and connect mouse and keyboard events.
364
365    For speed, the window is drawn in full only when needed (a new tree, a
366    zoom, a resize) and cached without the picture; each change then only
367    draws :meth:`OverlayAnnotator.composite` over the cache ("blitting").
368    The current tree and transform go in the window's title bar, which the
369    system draws.
370
371    Args:
372        ann: The annotator (or another with the same interface, e.g.
373            :class:`treeskel.annotate_mask.MaskAnnotator`).
374        show: Block in ``plt.show()`` (False only for tests).
375        help_text: Key help shown above the picture.
376
377    Returns:
378        The matplotlib figure.
379    """
380    import matplotlib.pyplot as plt
381
382    for k in ("keymap.save", "keymap.quit", "keymap.back", "keymap.forward", "keymap.pan",
383              "keymap.xscale", "keymap.yscale", "keymap.fullscreen"):
384        plt.rcParams[k] = []                        # free the tool's keys (s, q, arrows, k, l, f, ...)
385    plt.rcParams["keymap.home"] = ["h", "home"]     # and r (reset); h still resets the zoom
386    fig, ax = plt.subplots(figsize=(10, 8.2))
387    fig.subplots_adjust(0.005, 0.005, 0.995, 0.93)
388    ax.set_axis_off()
389    fig.suptitle(help_text, fontsize=8)
390    picture = ax.imshow(np.zeros((480, 640, 3), np.uint8), interpolation="nearest", animated=True)
391    canvas = fig.canvas
392    st = {"tree": None, "drag": None, "bg": None}
393
394    def on_draw(ev) -> None:
395        """After a full draw: cache it (without the picture), then draw the picture on top."""
396        st["bg"] = canvas.copy_from_bbox(fig.bbox)
397        fig.draw_artist(picture)
398
399    def status() -> None:
400        """Show the prompt's first lines in the window's title bar."""
401        manager = getattr(canvas, "manager", None)
402        if manager is not None:
403            lines = ann.prompt().splitlines()
404            manager.set_window_title(lines[0] if ann.done else f"{lines[0]}   |   {lines[1]}")
405
406    def update() -> None:
407        """Redraw the picture: a full draw for a new tree, else only the picture (blitted, for speed)."""
408        status()
409        if ann.done:
410            picture.set_data(np.zeros((480, 640, 3), np.uint8))
411            canvas.draw_idle()
412            return
413        picture.set_data(ann.composite())
414        if st["tree"] != ann.tree.tree_id:          # a new tree: show all of it (a full draw)
415            ax.set_xlim(-0.5, 639.5)
416            ax.set_ylim(479.5, -0.5)
417            st["tree"] = ann.tree.tree_id
418            canvas.draw_idle()
419        elif st["bg"] is None:
420            canvas.draw_idle()
421        else:                                        # the same view: only the picture changes
422            canvas.restore_region(st["bg"])
423            fig.draw_artist(picture)
424            canvas.blit(fig.bbox)
425
426    def tool_active() -> bool:
427        """Whether the toolbar's zoom or pan is switched on (then clicks are not drags)."""
428        toolbar = getattr(canvas, "toolbar", None)
429        return toolbar is not None and bool(getattr(toolbar, "mode", ""))
430
431    def on_press(ev) -> None:
432        """Start a drag: remember where it started, and the shift for undo."""
433        if ann.done or ev.button != 1 or ev.inaxes is not ax or ev.xdata is None or tool_active():
434            return
435        ann.history.append(replace(ann.ov))
436        st["drag"] = (ev.xdata, ev.ydata, ann.ov.dx, ann.ov.dy)
437
438    def on_motion(ev) -> None:
439        """Move the overlay with the mouse while dragging."""
440        if st["drag"] is None or ev.xdata is None:
441            return
442        x0, y0, dx0, dy0 = st["drag"]
443        ann.ov.dx, ann.ov.dy = dx0 + ev.xdata - x0, dy0 + ev.ydata - y0
444        update()
445
446    def on_release(ev) -> None:
447        """End a drag; a click that moved nothing leaves no undo step."""
448        if st["drag"] is None:
449            return
450        st["drag"] = None
451        if ann.history and ann.history[-1] == ann.ov:
452            ann.history.pop()                        # a click without a drag changes nothing
453        update()
454
455    def on_scroll(ev) -> None:
456        """Scroll to scale the overlay about the mouse."""
457        if ann.done or ev.inaxes is not ax or ev.xdata is None:
458            return
459        ann.rescale(STEPS["scroll"] if ev.button == "up" else 1 / STEPS["scroll"], about=(ev.xdata, ev.ydata))
460        update()
461
462    def on_key(ev) -> None:
463        """Pass a key to the annotator; ``q`` closes the window."""
464        if ev.key is None:
465            return
466        ann.key(ev.key)
467        if ev.key == "q":
468            plt.close(fig)
469        else:
470            update()
471
472    for name, fn in (("draw_event", on_draw), ("button_press_event", on_press),
473                     ("motion_notify_event", on_motion), ("button_release_event", on_release),
474                     ("scroll_event", on_scroll), ("key_press_event", on_key)):
475        canvas.mpl_connect(name, fn)
476    update()
477    if show:  # pragma: no cover - needs a display
478        plt.show()
479    return fig
