Dataset indexing and image loading for the orchard RGB-D dataset.

The dataset used ("Dataset (With Summer GT)") has five PNG files per tree::

R20N03_Summer_RGB-14-21-52.png   640x480 colour
R20N03_Summer_D-14-21-52.png     640x480 depth
R20N03_Summer_GT-14-21-52.png    256x256 main-branch mask (summer only)
R20N03_Winter_RGB-13-26-42.png   640x480 colour
R20N03_Winter_D-13-26-42.png     640x480 depth

The name encodes the orchard row (R20), the tree number within the row (N03), the season, the file type (RGB, D for depth or GT for the mask) and the capture clock time H-M-S (not zero-padded, e.g. 14-22-1). R and N follow the orchard map supplied with the dataset: rows run west to east and N counts trees north to south, so R20N03_Summer and R20N03_Winter are the same physical tree.

An earlier version of the dataset numbered trees by photo order (U, for "unmatched", e.g. R01U01). Those names are still accepted, but U numbers are not guaranteed to be the same tree in both seasons, so that version is not used.

Masks are hand-labelled, 256x256, and assumed to use the same geometry as Chen et al. (2020): the photo's centre 480x480 (columns 80-559) resized to 256x256. to_mask_frame() and mask_to_image_frame() convert between the two frames.

Masks do not line up exactly with the summer photos. Overlays on the sample show the right shape, but shifted left of the visible trunk by about 15-45 px, with the shift varying from tree to tree (see docs/figures/mask_alignment_R12N02.jpg). Stretching the mask to the full width fits worse. The masks may have been drawn on a slightly different view (e.g. the paper's autumn images), so pixel-level comparisons need a per-tree alignment first.

The row 4 winter files in the U version use a variant that also embeds an original capture id, with an underscore before the time::

R04U01_Winter_RGB-R04N03_RGB_12-17-14.png

The embedded id (R04N03) is kept as FileInfo.source_id. Its row must match the outer row, or the file is rejected. Its modality is not trusted: every row 4 winter depth file embeds _RGB_ (e.g. R04U01_Winter_D-R04N03_RGB_12-17-14.png), so the outer D/RGB label decides the modality, and the embedded one is kept as FileInfo.source_modality for reporting. load_depth() rejects any "depth" file that is really a colour image, which catches a wrong outer label.

Depth images are stored as 8-bit greyscale (three identical channels). They are a scaled visualisation of depth, not metric distance: brighter pixels are closer to the camera and 0 means "no reading" (out of range or sensor dropout).

The depth does not line up exactly with the colour image. The winter depth sits about 5 px below the colour image and about 1 px to its left (docs/results/depth_registration/). load_tree() moves it by DEPTH_SHIFT to correct this (register=False loads it as stored); the shift is measured by treeskel.measure_registration.

132@dataclass(frozen=True)
133class FileInfo:
134    """Metadata parsed from a single dataset filename.
135
136    Attributes:
137        tree_id: Tree code, e.g. ``"R20N03"``.
138        row: Orchard row number (the ``20`` in ``R20``).
139        position: Tree number within its row (the ``03`` in ``N03``).
140        season: ``"summer"`` or ``"winter"``.
141        modality: ``"rgb"``, ``"depth"`` or ``"mask"``.
142        time: Capture clock time as ``"HH:MM:SS"``.
143        source_id: Embedded original capture id such as ``"R04N03"``, or
144            ``None`` for the standard naming.
145        source_modality: Modality written in the embedded id (``"rgb"`` or
146            ``"depth"``), or ``None``. May disagree with ``modality``.
147    """
148
149    tree_id: str
150    row: int
151    position: int
152    season: str
153    modality: str
154    time: str
155    source_id: str | None = None
156    source_modality: str | None = None

159def parse_filename(name: str | Path) -> FileInfo:
160    """Parse a dataset filename into its components.
161
162    Args:
163        name: Filename or path, e.g. ``"R20N03_Summer_D-14-21-52.png"``.
164
165    Returns:
166        The parsed :class:`FileInfo`.
167
168    Raises:
169        ValueError: If the name does not follow the dataset naming convention,
170            has an impossible time, or embeds an id whose row disagrees with
171            the outer name.
172
173    Example:
174        >>> parse_filename("R20N05_Summer_GT-14-22-1.png").modality
175        'mask'
176        >>> parse_filename("R02U10_Summer_RGB-12-52-3.png").time
177        '12:52:03'
178        >>> parse_filename("R04U01_Winter_RGB-R04N03_RGB_12-17-14.png").source_id
179        'R04N03'
180    """
181    base = Path(name).name
182    m = _FILENAME_RE.match(base)
183    if m is None:
184        raise ValueError(f"Filename does not match dataset convention: {base!r}")
185    row, pos = int(m["row"]), int(m["pos"])
186    h, mi, s = int(m["h"]), int(m["m"]), int(m["s"])
187    if not (h < 24 and mi < 60 and s < 60):
188        raise ValueError(f"Invalid capture time in filename: {base!r}")
189    source_id = source_modality = None
190    if m["src_row"] is not None:
191        # A row mismatch would mean the file was renamed to the wrong tree.
192        if int(m["src_row"]) != row:
193            raise ValueError(f"Embedded row disagrees with filename: {base!r}")
194        source_id = f"R{int(m['src_row']):02d}N{int(m['src_num']):02d}"
195        source_modality = "rgb" if m["src_mod"].upper() == "RGB" else "depth"
196    return FileInfo(
197        # Rebuild the id so "r1n1" and "R01N01" style variants map to one tree.
198        tree_id=f"R{row:02d}{m['kind'].upper()}{pos:02d}",
199        row=row,
200        position=pos,
201        season=m["season"].lower(),
202        modality=_MODALITIES[m["modality"].upper()],
203        time=f"{h:02d}:{mi:02d}:{s:02d}",
204        source_id=source_id,
205        source_modality=source_modality,
206    )

209@dataclass
210class TreeRecord:
211    """All files belonging to one tree.
212
213    Attributes:
214        tree_id: Tree code, e.g. ``"R20N03"``.
215        row: Orchard row number, used as the grouping key for splits.
216        position: Tree number within its row.
217        paths: Mapping ``(season, modality) -> Path`` of the files found.
218    """
219
220    tree_id: str
221    row: int
222    position: int
223    paths: dict[tuple[str, str], Path] = field(default_factory=dict)
224
225    def missing(self) -> list[tuple[str, str]]:
226        """Return the ``(season, modality)`` pairs that have no file."""
227        return [
228            (s, mod)
229            for s in SEASONS
230            for mod in ("rgb", "depth")
231            if (s, mod) not in self.paths
232        ]
233
234    @property
235    def is_complete(self) -> bool:
236        """True if all four images (2 seasons x RGB/depth) are present.
237
238        The mask is not required: a tree without one still has its winter
239        ground truth (the segmentation of :mod:`treeskel.segment` trains only
240        on trees that have one).
241        """
242        return not self.missing()
243
244    @property
245    def has_mask(self) -> bool:
246        """True if the tree has a summer mask."""
247        return ("summer", "mask") in self.paths

250@dataclass
251class DatasetIndex:
252    """Result of scanning a data directory.
253
254    Attributes:
255        trees: Complete trees (all four images present), sorted by id.
256        incomplete: Trees missing at least one image; excluded from ``trees``.
257        unrecognised: Files whose names did not match the convention.
258        duplicates: Files that repeat an already-seen ``(tree, season, modality)``.
259        excluded: Trees deliberately left out (see :data:`EXCLUDED_ROWS` and
260            :data:`EXCLUDED_TREES`), whether complete or not; not in
261            ``trees`` or ``incomplete``.
262    """
263
264    trees: list[TreeRecord]
265    incomplete: list[TreeRecord]
266    unrecognised: list[Path]
267    duplicates: list[Path]
268    excluded: list[TreeRecord] = field(default_factory=list)
269
270
271def index_dataset(
272    root: str | Path,
273    exclude_rows: Iterable[int] | None = None,
274    exclude_trees: Iterable[str] | None = None,
275) -> DatasetIndex:
276    """Scan a directory (recursively) and group image files by tree.
277
278    Invalid inputs are reported rather than raised, so a single bad file does
279    not stop a run over the full dataset: badly named files go to
280    ``unrecognised``, repeated files to ``duplicates`` (the first one found in
281    sorted order is kept), and trees without all four images to ``incomplete``.
282    Trees in excluded rows, and excluded individual trees, go to ``excluded``. Masks are optional (see
283    :attr:`TreeRecord.has_mask`).
284
285    Args:
286        root: Directory containing the PNG files (sub-folders are searched).
287        exclude_rows: Rows to leave out. ``None`` (default) uses
288            :data:`EXCLUDED_ROWS`; pass ``()`` to keep every row.
289        exclude_trees: Tree ids to leave out. ``None`` (default) uses
290            :data:`EXCLUDED_TREES`; pass ``()`` to keep every tree.
291
292    Returns:
293        A :class:`DatasetIndex`.
294
295    Raises:
296        FileNotFoundError: If ``root`` does not exist or is not a directory.
297    """
298    root = Path(root)
299    if not root.is_dir():
300        raise FileNotFoundError(f"Data directory not found: {root}")
301
302    records: dict[str, TreeRecord] = {}
303    unrecognised: list[Path] = []
304    duplicates: list[Path] = []
305
306    for path in sorted(root.rglob("*.png")):
307        try:
308            info = parse_filename(path)
309        except ValueError:
310            unrecognised.append(path)
311            continue
312        rec = records.setdefault(
313            info.tree_id, TreeRecord(info.tree_id, info.row, info.position)
314        )
315        key = (info.season, info.modality)
316        if key in rec.paths:
317            duplicates.append(path)
318        else:
319            rec.paths[key] = path
320
321    skip_rows = set(EXCLUDED_ROWS if exclude_rows is None else exclude_rows)
322    skip_trees = set(EXCLUDED_TREES if exclude_trees is None else exclude_trees)
323
324    def skipped(r: TreeRecord) -> bool:
325        """Whether a tree is in an excluded row or on the excluded-tree list."""
326        return r.row in skip_rows or r.tree_id in skip_trees
327
328    ordered = [records[k] for k in sorted(records)]
329    kept = [r for r in ordered if not skipped(r)]
330    return DatasetIndex(
331        trees=[r for r in kept if r.is_complete],
332        incomplete=[r for r in kept if not r.is_complete],
333        unrecognised=unrecognised,
334        duplicates=duplicates,
335        excluded=[r for r in ordered if skipped(r)],
336    )

339def find_identical_images(paths: Iterable[str | Path]) -> list[list[Path]]:
340    """Find groups of files whose pixel content is exactly identical.
341
342    Different trees should never share an image, so any group returned points
343    to a copying or export error (this is how row 4's repeated winter depth
344    images were found). Pixels are compared, not file bytes, so the same image
345    saved with different PNG settings still counts as identical.
346
347    Args:
348        paths: Image files to compare.
349
350    Returns:
351        Groups of two or more identical files, each sorted, ordered by first
352        file name.
353    """
354    groups: dict[str, list[Path]] = defaultdict(list)
355    for p in paths:
356        p = Path(p)
357        arr = np.asarray(Image.open(p))
358        h = hashlib.sha1(str(arr.shape).encode() + arr.tobytes()).hexdigest()
359        groups[h].append(p)
360    return sorted((sorted(g) for g in groups.values() if len(g) > 1),
361                  key=lambda g: g[0].name)

371def load_rgb(path: str | Path) -> np.ndarray:
372    """Load an RGB image.
373
374    Args:
375        path: Path to an RGB PNG.
376
377    Returns:
378        ``uint8`` array of shape ``(480, 640, 3)``.
379
380    Raises:
381        ValueError: If the image is not 640x480.
382    """
383    path = Path(path)
384    arr = np.asarray(Image.open(path).convert("RGB"))
385    _check_shape(arr, path)
386    return arr

389def load_depth(path: str | Path) -> tuple[np.ndarray, np.ndarray]:
390    """Load an 8-bit depth image and its validity mask.
391
392    The dataset stores depth as greyscale in all three channels. Values are
393    relative (brighter = closer), not metric; converting to metres needs a
394    calibrated mapping, which is estimated elsewhere.
395
396    Args:
397        path: Path to a depth PNG.
398
399    Returns:
400        ``(depth, valid)`` where ``depth`` is a ``uint8`` array of shape
401        ``(480, 640)`` and ``valid`` is a boolean array that is False where the
402        sensor gave no reading (value 0).
403
404    Raises:
405        ValueError: If the image is not 640x480, or if its colour channels
406            differ (i.e. it is not a greyscale depth map).
407    """
408    path = Path(path)
409    arr = np.asarray(Image.open(path))
410    _check_shape(arr, path)
411    if arr.ndim == 3:
412        chans = arr[..., :3]
413        if not (np.array_equal(chans[..., 0], chans[..., 1])
414                and np.array_equal(chans[..., 0], chans[..., 2])):
415            raise ValueError(f"{path.name}: depth channels differ; not a depth map")
416        arr = chans[..., 0]
417    depth = arr.astype(np.uint8, copy=False)
418    return depth, depth > 0

421def shift_image(image: np.ndarray, shift: tuple[int, int], fill=0) -> np.ndarray:
422    """Move an image by whole pixels, filling the uncovered edge.
423
424    Args:
425        image: ``(H, W)`` or ``(H, W, C)`` array.
426        shift: ``(rows, cols)``; positive moves the content down and right.
427        fill: Value for the pixels the move uncovers (for depth, 0 = no reading).
428
429    Returns:
430        A new array the shape and dtype of ``image``: ``out[r + rows, c + cols] =
431        image[r, c]`` wherever both are inside the image.
432
433    Example:
434        >>> shift_image(np.arange(1, 7).reshape(2, 3), (1, -1)).tolist()
435        [[0, 0, 0], [2, 3, 0]]
436    """
437    dy, dx = (int(v) for v in shift)
438    h, w = image.shape[:2]
439    out = np.full_like(image, fill)
440    if abs(dy) < h and abs(dx) < w:
441        out[max(dy, 0):h + min(dy, 0), max(dx, 0):w + min(dx, 0)] = \
442            image[max(-dy, 0):h - max(dy, 0), max(-dx, 0):w - max(dx, 0)]
443    return out

446def load_tree(rec: TreeRecord, season: str, register: bool = True) -> dict[str, np.ndarray]:
447    """Load the RGB image, depth and validity mask for one tree and season.
448
449    Args:
450        rec: A complete :class:`TreeRecord`.
451        season: ``"summer"`` or ``"winter"`` (case-insensitive).
452        register: Move the depth by the season's :data:`DEPTH_SHIFT` so that it
453            lines up with the colour image (pixels it uncovers get no reading).
454            False returns the depth as stored, e.g. to measure the shift.
455
456    Returns:
457        Dict with keys ``"rgb"`` (480x640x3 uint8), ``"depth"`` (480x640
458        uint8) and ``"valid"`` (480x640 bool).
459
460    Raises:
461        ValueError: If ``season`` is unknown.
462        KeyError: If the record is missing that season's files.
463    """
464    season = season.lower()
465    if season not in SEASONS:
466        raise ValueError(f"Unknown season {season!r}; expected one of {SEASONS}")
467    depth, valid = load_depth(rec.paths[(season, "depth")])
468    if register and any(DEPTH_SHIFT[season]):
469        depth = shift_image(depth, DEPTH_SHIFT[season])
470        valid = depth > 0
471    return {"rgb": load_rgb(rec.paths[(season, "rgb")]), "depth": depth, "valid": valid}

474def load_mask(path: str | Path) -> np.ndarray:
475    """Load a 256x256 main-branch mask as a boolean array.
476
477    Masks are white (branch) on black. Pixels brighter than 127 count as
478    branch, so light anti-aliasing at the edges does not matter.
479
480    Args:
481        path: Path to a ``_GT`` mask PNG.
482
483    Returns:
484        ``bool`` array of shape ``(256, 256)``, True on branch pixels.
485
486    Raises:
487        ValueError: If the mask is not 256x256 or is not greyscale.
488    """
489    path = Path(path)
490    arr = np.asarray(Image.open(path))
491    if arr.shape[:2] != MASK_SHAPE:
492        raise ValueError(f"{path.name}: expected {MASK_SHAPE} mask, got {arr.shape[:2]}")
493    if arr.ndim == 3:
494        chans = arr[..., :3]
495        if not (np.array_equal(chans[..., 0], chans[..., 1])
496                and np.array_equal(chans[..., 0], chans[..., 2])):
497            raise ValueError(f"{path.name}: mask channels differ; not a mask")

531    """Map a 256x256 mask back onto the full 640x480 photo.
532
533    Args:
534        mask: ``bool`` array of shape ``(256, 256)``.
535
536    Returns:
537        ``(full, covered)``: ``full`` is a ``(480, 640)`` bool mask; ``covered``
538        is True on the columns the mask describes (80-559). Outside
539        ``covered``, the mask says nothing, so those pixels must be ignored
540        in evaluation rather than treated as "not branch".

542    Raises:
543        ValueError: If ``mask`` is not 256x256.
544    """
545    if mask.shape != MASK_SHAPE:
546        raise ValueError(f"expected {MASK_SHAPE} mask, got {mask.shape}")
547    side = IMAGE_SHAPE[0]
548    big = Image.fromarray(mask.astype(np.uint8) * 255).resize((side, side), Image.NEAREST)
549    full = np.zeros(IMAGE_SHAPE, bool)
550    full[:, CROP_COLS[0]:CROP_COLS[1]] = np.asarray(big) > 127
551    covered = np.zeros(IMAGE_SHAPE, bool)
552    covered[:, CROP_COLS[0]:CROP_COLS[1]] = True
553    return full, covered

295

302

422def shift_image(image: np.ndarray, shift: tuple[int, int], fill=0) -> np.ndarray:
423    """Move an image by whole pixels, filling the uncovered edge.
424
425    Args:
426        image: ``(H, W)`` or ``(H, W, C)`` array.
427        shift: ``(rows, cols)``; positive moves the content down and right.
428        fill: Value for the pixels the move uncovers (for depth, 0 = no reading).
429
430    Returns:
431        A new array the shape and dtype of ``image``: ``out[r + rows, c + cols] =
432        image[r, c]`` wherever both are inside the image.
433
434    Example:
435        >>> shift_image(np.arange(1, 7).reshape(2, 3), (1, -1)).tolist()
436        [[0, 0, 0], [2, 3, 0]]
437    """
438    dy, dx = (int(v) for v in shift)
439    h, w = image.shape[:2]
440    out = np.full_like(image, fill)
441    if abs(dy) < h and abs(dx) < w:
442        out[max(dy, 0):h + min(dy, 0), max(dx, 0):w + min(dx, 0)] = \
443            image[max(-dy, 0):h - max(dy, 0), max(-dx, 0):w - max(dx, 0)]
444    return out

531def mask_to_image_frame(mask: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
532    """Map a 256x256 mask back onto the full 640x480 photo.
533
534    Args:
535        mask: ``bool`` array of shape ``(256, 256)``.
536
537    Returns:
538        ``(full, covered)``: ``full`` is a ``(480, 640)`` bool mask; ``covered``
539        is True on the columns the mask describes (80-559). Outside
540        ``covered``, the mask says nothing, so those pixels must be ignored
541        in evaluation rather than treated as "not branch".
542
543    Raises:
544        ValueError: If ``mask`` is not 256x256.
545    """
546    if mask.shape != MASK_SHAPE:
547        raise ValueError(f"expected {MASK_SHAPE} mask, got {mask.shape}")
548    side = IMAGE_SHAPE[0]
549    big = Image.fromarray(mask.astype(np.uint8) * 255).resize((side, side), Image.NEAREST)
550    full = np.zeros(IMAGE_SHAPE, bool)
551    full[:, CROP_COLS[0]:CROP_COLS[1]] = np.asarray(big) > 127
552    covered = np.zeros(IMAGE_SHAPE, bool)
553    covered[:, CROP_COLS[0]:CROP_COLS[1]] = True
554    return full, covered
